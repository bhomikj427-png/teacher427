This folder is **not a live reference.** The leading underscore marks it as "ignore for any
teaching or evidence decision." It preserves the two earlier research dives exactly as they were
written, so the reasoning behind the canonical `../research/` base can always be traced (and so
nothing was "merged in secret").

- **`dive-1-original/`** — the first deep dive. The original evidence base.
- **`dive-2-independent/`** — the second, independent red-team review that cross-checked Dive 1,

Both were then reconciled — plus six techniques neither had — into the single canonical
**`../research/`** folder, which is the only one the engine uses.
