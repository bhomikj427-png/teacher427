# digital-arts — creative-software subjects

A group folder for digital-art subjects, nested the same way as `../sem-3/`
(`digital-arts/NN-subject/`, same internal shape as every subject: `knowledge-base/`, `curriculum.md`,
`learner-profile.md`, `progress-log.md`, `study-pack/web/`). Created 2026-09-28 at the learner's request.

This README describes the **shape** only. What is built, studied or mastered lives in each subject's
`progress-log.md`, never here.

## How the engine rules apply here

- **Teaching gate:** unchanged. A subject is taught only at `stage-2✓` (`../README.md`).
- **No professor, no syllabus.** A software subject has no course hand-out, so each subject's
  `course-info.md` writes down the **scope** (the goal the learner stated), and that scope plays the role
  of the syllabus for Stage 1.
- **Source of truth = the vendor's official documentation** (for After Effects: Adobe's user guide).
  It plays the role the prescribed textbook plays for a university subject. Third-party tutorials and
  cheat sheets are tier 3: used to cross-check and to catch version changes, never to set a fact alone.
- **Version drift is a standing risk.** Creative software changes every release. Each KB records the
  version its sources describe, and each version-sensitive claim is marked so it can be re-checked.
- **The end product is the exam.** There is no paper to pass. Each subject's final chapter is a build
  that produces a real file, and the build is what shows whether the skill transferred.
