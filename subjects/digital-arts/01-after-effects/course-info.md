# After Effects — course info (scope, goal, sources)

> This subject has no official syllabus. This file **is** the syllabus: the scope the learner set on
> 2026-09-28. Stage 1 is bounded by it. Anything outside it is listed under *Out of scope* so it is a
> decision, not an omission.

## The learner's goal (stated 2026-09-28)
> "what i want atleast is explaining layout and what how to operate the software, shortcut list and what
> they do, and whatever usefullness i need from it, i wanna give it one good night and learn most of it
> and hopefully get some result … i wanna get some end product from it even if it doesnt get finished"

Read as four deliverables:
1. **Layout:** what every default panel is for and how they connect.
2. **Operation:** project → composition → layer → property → keyframe → render, done by hand.
3. **Shortcuts:** a verified list with what each key does, ranked by how often a beginner needs it.
4. **An end product tonight:** a short motion-graphics piece exported to an .mp4 file.

## Scope (the Stage-1 "syllabus")

| Unit | Title | Covers |
|---|---|---|
| 01 | Interface & project | Home screen, workspaces, the default panels, viewers, project/composition/footage, composition settings, import, save |
| 02 | Layers & transforms | layer types, stacking order, the five transform properties, anchor point, parenting and nulls, switches, trimming and splitting |
| 03 | Keyframes & motion | stopwatch, keyframes, interpolation (linear, Bezier family, hold), Easy Ease, Graph Editor (value vs speed), motion paths |
| 04 | Shapes, text, masks, mattes | shape-layer anatomy, path operations (Trim Paths, Repeater), text layers and animators, masks, track mattes |
| 05 | Effects, precomps, expressions | Effects & Presets, adjustment layers, precompose/nesting, render order, starter expressions (wiggle, time, loopOut) |
| 06 | Preview & export | preview and cache, resolution, Render Queue (render settings, output module, output to), H.264, Media Encoder, Collect Files |
| — | Shortcuts | the verified reference, `knowledge-base/shortcuts.md` |
| — | Build | tonight's end product (curriculum.md → *The build*) |

## Out of scope (parked, not forgotten)
3D layers, cameras and lights beyond a mention; motion tracking and camera tracking; Roto Brush and
Content-Aware Fill; keying (green screen); puppet tools; CINEMA 4D renderer and 3D models; Essential
Graphics / Motion Graphics templates; scripting (ExtendScript). Each is a later unit if the learner wants it.

## Version
- Current release when researched: **After Effects 2026 (26.5), released 2026-09-10** (Wikipedia).
- The tier-1 user guide is Adobe's PDF (archived 2025-06-13). Most of its chapters carry a "Last updated
  11/4/2019" footer (AE 17.0 era). Fundamentals (panels, layers, keyframes, render order, shortcuts) are
  stable across these versions. Known changes since then are corrected in the KB and logged in
  `knowledge-base/CHANGELOG.md`. Version-sensitive claims are marked `[version]` in the KB.
