# After Effects — shortcut reference (Windows)

> Truth = Adobe's shortcut tables [UG p.9–30]. Cross-checked against two 2026 third-party lists
> (`sources.md`). Mac: Ctrl → Cmd, Alt → Option. Numpad keys need Num Lock on. Double letters (UU, EE)
> = press twice quickly. Live bindings in your install: **Edit > Keyboard Shortcuts (Ctrl+Alt+')**.
> Tier = how soon a beginner needs it. **Tier 1 = tonight.** Machine-checked by `study-pack/web/verify.py`
> (every key shown on the site must appear in this file with the same meaning).

## Not a shortcut, but constant
- **Alt-click a stopwatch** → add expression. **Click a property name** → select all its keyframes.
- **Double-click a layer** → Layer panel (precomp: opens the precomp). **Double-click the Selection tool**
  → scale 100 %; **double-click the Rotation tool** → rotation 0. [UG p.21, 24]
