Stability factor for voltage divider
Assume E0 = Eth and R0 = Rth

E0 - IB * R0 - VBE - IE * RE = 0
or
E0 = IB * R0 + VBE + (IB + IC) * RE

Considering VBE to be constant and differentiating the above equation w.r.t. IC, we have,
0 = R0 * (dIB / dIC) + 0 + RE * (dIB / dIC) + RE

or
0 = (dIB / dIC) * (R0 + RE) + RE

∴ dIB / dIC = - RE / (R0 + RE)    ...(i)

## slide 36

Stability factor for voltage divider

Stability factor, S = (β + 1) / (1 - β * (dIB / dIC))

Putting the value of dIB/dIC from eq. (i) into the expression for S, we have,
S = (β + 1) / (1 - β * (- RE / (R0 + RE))) = (β + 1) / (1 + (β * RE / (R0 + RE)))
  = ((β + 1)(R0 + RE)) / (R0 + RE + β * RE) = ((β + 1)(R0 + RE)) / (R0 + RE * (β + 1))

∴ S = (β + 1) * (R0 + RE) / (RE * (β + 1) + R0)

Dividing the numerator and denominator of R.H.S. of the above equation by RE, we have,
S = (β + 1) * (1 + R0 / RE) / (β + 1 + R0 / RE)    ...(ii)

Eq. (ii) gives the formula for the stability factor S for the potential divider bias circuit. The following points may be noted carefully :

(i) For greater thermal stability, the value of S should be small. This can be achieved by making R0 / RE small. If R0 / RE is made very small, then it can be neglected as compared to 1.

∴ S = (β + 1) * 1 / (β + 1) = 1

- Note: Derivation and explanatory points are provided in image s036-image36.png, transcribed above.

## slide 37

Stability factor for voltage divider

This is the ideal value of S and leads to the maximum thermal stability.

(ii) The ratio *R0 / RE can be made very small by decreasing R0 and increasing RE. Low value of R0 can be obtained by making R2 very small. But with low value of R2, current drawn from VCC will be large. This puts restriction on the choice of R0. Increasing the value of RE requires greater VCC in order to maintain the same zero signal collector current. Due to these limitations, a compromise is made in the selection of the values of R0 and RE. Generally, these values are so selected that S ≃ 10.

Phase reversal

The following points regarding the input / output phase relationships between currents and voltages for the various transistor configurations may be noted :
(i) For every amplifier type (CE, CB and CC), the input and output currents are in phase. When the input current decreases, the output current also decreases and vice-versa.
(ii) Remember that common emitter (CE) circuit is the only configuration that has input and output voltages 180° out of phase.
(iii) For both common base (CB) and common collector (CC) circuits, the input and output voltages are in phase. If the input voltage decreases, the output voltage also decreases and vice-versa.
