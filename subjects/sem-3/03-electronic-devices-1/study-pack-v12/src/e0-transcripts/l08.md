Load-Line Analysis
A straight line is defined by the parameters of the network.
It is called the load line because the intersection on the vertical axes is defined by the applied load R.

- Graph [s002-image3.jpg]: Graph of diode current ID versus diode voltage VD showing origin 0, exponential diode curve labeled "Characteristics (device)", straight load line labeled "Load line (network)" connecting vertical-axis intercept ID = E/R to horizontal-axis intercept VD = E, and intersection point labeled "Q-point" with dashed projection lines to IDQ on the vertical axis and VDQ on the horizontal axis.

## slide 3

Load-Line Analysis
The maximum ID equals E/R, and the maximum VD equals E.
The point where the load line and the characteristic curve intersect is the Q-point, which identifies ID and VD for a particular diode in a given circuit.

- Graph [s003-image3.jpg]: Graph of ID versus VD showing origin 0, exponential diode curve labeled "Characteristics (device)", linear line labeled "Load line (network)" connecting vertical intercept (0, E/R) to horizontal intercept (E, 0), intersecting at "Q-point" with dashed projections to coordinates (VDQ, IDQ).

## slide 6

Diode Configurations:
The forward resistance of the diode is usually so small compared to the other series elements of the network that it can be ignored.
In general, a diode is in the “on” state if the current established by the applied sources is such that its direction matches that of the arrow in the diode symbol, and VD≥0.7V for silicon, VD≥0.3V for germanium, and VD≥1.2V for gallium arsenide.
You may assume the diode is “on”, and then find the current in the diode. If the current flows into the positive terminal of the diode, then the assumption is right, otherwise, the diode is “off”.
