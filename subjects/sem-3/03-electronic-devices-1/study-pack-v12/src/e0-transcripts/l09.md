Ripple factor (Γ) The ratio of rms value of ac component to the dc component in the output is known as ripple factor (Γ)

Γ = rms value of ac component / dc value of component = Vr,rms / Vdc

where Vr,rms = sqrt(Vrms^2 - Vdc^2)

Γ = sqrt((Vrms / Vdc)^2 - 1)

Vav is the average or the dc content of the voltage across the load and is given by

Vav = Vdc = 1 / (2π) [ \int_0^π Vm sin ωt d(ωt) + \int_π^{2π} 0 . d(ωt) ]

= Vm / (2π) [ -cos ωt ]_0^π = Vm / π

Therefore, Idc = Vdc / RL = Vm / (π RL) = Im / π

RMS voltage at the load resistance can be calculated as

Vrms = [ 1 / (2π) \int_0^π Vm^2 sin^2 ωt d(ωt) ]^(1/2)

= Vm [ 1 / (4π) \int_0^π (1 - cos 2ωt) d(ωt) ]^(1/2) = Vm / 2

Therefore Γ = sqrt( [ (Vm / 2) / (Vm / π) ]^2 - 1 ) = sqrt( (π / 2)^2 - 1 ) = 1.21

From this expression it is clear that the amount of ac present in the output is 121% of the dc voltage. So the half-wave rectifier is not practically useful in converting ac into dc.

Efficiency (η) The ratio of dc output power to ac input power is known as rectifier efficiency (η).

η = dc output power / ac input power = Pdc / Pac

= ( (Vdc)^2 / RL ) / ( (Vrms)^2 / RL ) = (Vm / π)^2 / (Vm / 2)^2 = 4 / π^2 = 0.406 = 40.6%

The maximum efficiency of a half-wave rectifier is 40.6%.

Form Factor

Form factor = rms value / average value = (Vm / 2) / (Vm / π) = π / 2 = 1.57

Peak Factor

Peak factor = peak value / rms value = Vm / (Vm / 2) = 2

Efficiency

Ripple Factor (Γ)

Γ = sqrt((Vrms / Vdc)^2 - 1)

The average voltage or dc voltage available across the load resistance is

Vdc = 1 / π \int_0^π Vm sin ωt d(ωt) = (Vm / π) [ -cos ωt ]_0^π = 2 Vm / π

Idc = Vdc / RL = 2 Vm / (π RL) = 2 Im / π  and  Irms = Im / sqrt(2)

If the diode forward resistance (rf) and the transformer secondary winding resistance (rs) are included in the analysis, then

Vdc = (2 Vm / π) - Idc (rs + rf)

Idc = Vdc / ( (rs + rf) + RL ) = 2 Vm / ( π (rs + rf + RL) )

RMS value of the voltage at the load resistance is

Vrms = sqrt( 1 / π \int_0^π Vm^2 sin^2 ωt d(ωt) ) = Vm / sqrt(2)

Therefore, Γ = sqrt( [ (Vm / sqrt(2)) / (2 Vm / π) ]^2 - 1 ) = sqrt( π^2 / 8 - 1 ) = 0.482

η = dc output power / ac input power = Pdc / Pac

= ( (Vdc)^2 / RL ) / ( (Vrms)^2 / RL ) = [ 2 Vm / π ]^2 / [ Vm / sqrt(2) ]^2 = 8 / π^2 = 0.812 = 81.2%

## slide 25

Example 2.10 A 230 V, 60 Hz voltage is applied to the primary of a 5:1 step-down, center-tap transformer used in a full wave rectifier having a load of 900 Ω. If the diode resistance and secondary coil resistance together has a resistance of 100 Ω, determine (a) dc voltage across the load, (b) dc current flowing through the load, (c) dc power delivered to the load, (d) PIV across each diode, (e) ripple voltage and its frequency and (f) rectification efficiency.

- Problem statement image [s025-image37.png]: Text image of worked Example 2.10 specifying a 230 V, 60 Hz primary, 5:1 step-down center-tapped transformer, load RL = 900 Ω, total diode and secondary coil resistance rs + rf = 100 Ω, requesting parts (a) through (f).

## slide 26

Solution The voltage across the two ends of secondary = 230 / 5 = 46 V

Voltage from center tapping to one end, Vrms = 46 / 2 = 23 V

(a) dc voltage across the load,

Vdc = 2 Vm / π = (2 × 23 × √2) / π = 20.7 V

(b) dc current flowing through the load,

Idc = Vdc / (rs + rf + RL) = 20.7 / 1000 = 20.7 mA

(c) dc power delivered to the load,

Pdc = (Idc)^2 × RL = (20.7 × 10^(-3))^2 × 900 = 0.386 W

(d) PIV across each diode = 2 Vm = 2 × 23 × √2 = 65 V

(e) Ripple voltage,

Vr,rms = sqrt((Vrms)^2 - (Vdc)^2) = sqrt((23)^2 - (20.7)^2) = 10.05 V

Frequency of ripple voltage = 2 × 60 = 120 Hz

(f) Rectification efficiency,

η = Pdc / Pac = ( (Vdc)^2 / RL ) / ( (Vrms)^2 / RL ) = (Vdc)^2 / (Vrms)^2

= (20.7)^2 / (23)^2 = 428.49 / 529 = 0.81

Therefore, percentage of efficiency = 81%

⚠ looks wrong: In part (a), the solution labels Vdc = 2Vm/π = 20.7 V as "dc voltage across the load", but then in part (b) divides this value by total circuit resistance (rs + rf + RL = 1000 Ω) to obtain Idc = 20.7 mA; the actual DC voltage across the load resistor alone would be Idc * RL = (20.7 mA)(900 Ω) = 18.63 V (the 20.7 V is the open-circuit/internal average voltage before the internal drop across rs + rf).
