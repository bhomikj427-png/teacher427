The JFET (07) controls its channel with a reverse-biased junction. The MOSFET replaces that junction with a metal plate on a thin layer of glass. The idea is the same (a gate voltage sets the channel current), the equations are almost the same, and it is the transistor inside every digital chip (09).

Build

1 · Structure and the two types

Predict

With VGS = 0, an enhancement MOSFET carries no drain current but a depletion MOSFET does. What would have to exist between source and drain for current to flow?

Terms

Oxide: a very thin insulating layer of SiO2 under the gate. Substrate (body): the p-type silicon the device is built in, normally tied to the source. n⁺: heavily doped n-type.

  • Two n⁺ regions (source, drain) sit in a p substrate. With VGS = 0 the path is n–p–n: two diodes back to back, so no current.
  • A positive gate pushes holes away from the surface and attracts electrons. At the threshold voltage VT (also VGS(th)) the electrons form an n-type inversion layer: the channel.
  • More gate voltage, more electrons, more current: the gate enhances the channel.
Enhancement (E-MOSFET) Depletion (D-MOSFET)
Channel at VGS = 0 none: normally off built in: normally on
n-channel control VGS > VT (positive) turns it on negative VGS depletes, positive enhances
Saturation equation ID = K(VGS − VT)2 Shockley: ID = IDSS(1 − VGS/VGS(off))2, valid for positive VGS too
Symbol broken channel line solid channel line

The gate is insulated, so IG ≈ 0 and the input resistance is even higher than a JFET's (1010–1015 Ω). The thin oxide is destroyed by static charge, so MOSFETs need careful handling. A p-channel device reverses every voltage (VT negative).

Answer. Current needs a continuous channel of one type. An E-MOSFET has none at VGS = 0, only two back-to-back junctions, so it stays off until VGS > VT induces one. A D-MOSFET is made with the channel in place, so ID = IDSS flows at VGS = 0.

2 · Regions and the current equations

Sheet Q30

The data sheet for an E-MOSFET gives ID(on) = 500 mA at VGS = 10 V and VGS(th) = 1 V. Determine the drain current for VGS = 5 V.

Guess first

VGS is halved. Is the current halved?

Region Test (n-channel) Drain current Acts as
Cutoff VGS ≤ VT ID = 0 open switch
Triode (ohmic) VGS > VT, VDS < VGS − VT K[2(VGS − VT)VDS − VDS2] resistor set by VGS
Saturation VGS > VT, VDS ≥ VGS − VT K(VGS − VT)2 current source; amplifier
  • The region test is the first step of every MOSFET problem. VGS − VT is the overdrive.
  • K comes from one data-sheet point: K = ID(on)/(VGS(on) − VT)2. In device terms K = ½μnCox(W/L). Sedra & Smith write kn = 2K, so their equation reads ½kn(VGS − VT)2: same physics.
  • Channel-length modulation tilts the saturation curves: ID = K(VGS − VT)2(1 + λVDS), giving ro = 1/(λID).

Answer. K = 500/(10 − 1)2 = 500/81 = 6.17 mA/V2. At 5 V: ID = 6.17 × (5 − 1)2 = 98.8 mA (the sheet prints 98.7). Halving VGS cut the current by five, because the law squares the overdrive.

3 · Biasing

practice · biasing deck slides 10–16

In circuit (a), the E-MOSFET has K = 0.5 mA/V2 and VT = 2 V (VDD = 20 V, R1 = 7 MΩ, R2 = 3 MΩ, RD = 3 kΩ, RS = 1 kΩ). Find ID, VGS and VDS, and confirm the region.

Guess first

What is the gate voltage? (IG = 0, so nothing flows out of the divider.)

Circuit Gate–source loop Notes
Fixed bias VGS = VGG Q-point moves if K or VT change
Voltage divider (a) VG = VDDR2/(R1 + R2); VGS = VG − IDRS the usual choice
Drain feedback (b) no drop in RG: VGS = VDS = VDD − IDRD always in saturation, since VDS = VGS > VGS − VT
Self-bias (c) VGS = −IDRS depletion type only: negative VGS never turns on an E-MOSFET

Procedure, the same as 07: write VGS in terms of ID → put it into ID = K(VGS − VT)2 → keep the root with VGS > VT → VDS = VDD − ID(RD + RS) → check VDS ≥ VGS − VT. The DC load line VDS = VDD − IDRD ends at (0, VDD/RD) and (VDD, 0).

Answer. VG = 20 × 3/10 = 6 V, so VGS = 6 − ID (mA, kΩ). ID = 0.5(4 − ID)2 gives ID2 − 10ID + 16 = 0: ID = 2 or 8 mA. 8 mA makes VGS = −2 V, below VT: reject. ID = 2 mA, VGS = 4 V, VDS = 20 − 2(3 + 1) = 12 V. 12 ≥ 4 − 2 = 2 V: saturation ✓.

4 · Small signal: CS, CD and CG amplifiers

practice · syllabus Unit 4

The MOSFET of step 3 is biased at VGS = 4 V, ID = 2 mA. Find gm, and the gain of a common-source stage with RD = 3 kΩ. Neglect ro.

Guess first

Will the formula for gain look like the JFET's (07 §6)? What changes?

Differentiating ID = K(VGS − VT)2:

gm = 2K(VGS − VT) = 2√(K ID) = 2ID/(VGS − VT)

"Common" names the terminal at AC ground, shared by input and output.

Answer. gm = 2 × 0.5 × (4 − 2) = 2 mS (check: 2√(0.5 × 2) = 2 mS). Av = −2 mS × 3 kΩ = −6.

Check 4

With gm = 2 mS: (a) the input resistance of a common-gate stage; (b) the gain of a source follower with RS = 1 kΩ; (c) the bias current rises from 2 mA to 8 mA: the new gm?

Exam form

Structure and operation. Sketch: p substrate, n⁺ source and drain, oxide, gate. VGS = 0: back-to-back junctions, no current. VGS > VT: inversion layer forms the channel. E-type normally off; D-type normally on (channel built in). Insulated gate: IG ≈ 0.

Equations. Cutoff VGS ≤ VT. Triode: K[2(VGS − VT)VDS − VDS2]. Saturation (VDS ≥ VGS − VT): K(VGS − VT)2. K = ID(on)/(VGS(on) − VT)2. D-MOSFET: Shockley.

Bias procedure. Gate loop → substitute → reject root with VGS < VT → VDS → region check.

Small signal. gm = 2K(VGS − VT) = 2√(KID). CS −gmRD; CD gmRS/(1 + gmRS); CG +gmRD, Rin = 1/gm.

Traps

  • Skipping the region test, then using the saturation equation in triode.
  • Using self-bias with an enhancement device: VGS would be negative, and it never turns on.
  • Keeping the quadratic root with VGS < VT.
  • Mixing K and kn = 2K between books: check which form the question uses.
  • For a D-MOSFET with positive VGS, ID > IDSS: that is correct, not an error.
  • gm grows with √ID, not with ID.

  1. Draw an n-channel E-MOSFET and explain how the channel forms.
  2. An E-MOSFET has K = 0.25 mA/V2, VT = 2 V. Find ID at VGS = 6 V in saturation, and gm there.
  3. Sheet Q26 For the D-MOSFET of Check 2(a), find VGS for ID = 2.5 mA.
  4. State the condition for saturation and explain physically why ID stops depending on VDS.
  5. A CS stage has gm = 4 mS, RD = 2 kΩ and an unbypassed RS = 0.5 kΩ. Find Av.
  6. Compare E-MOSFET and D-MOSFET in four points.

Answers

Check 1. (a) Metal: the gate electrode. Oxide: the SiO2 insulator. Semiconductor: the silicon where the channel forms. (b) A thin layer of electrons at the surface of the p substrate, attracted by a positive gate; it is n-type, so it joins source to drain. (c) The oxide is an insulator: only a capacitor-charging current flows, none in steady state.

Check 2. (a) (i) n-channel: VGS(off) is negative. (ii) 10(1 − 3/8)2 = 3.91 mA. (iii) 10(1 + 3/8)2 = 18.9 mA, above IDSS because positive VGS enhances. (b) Overdrive 2 V. VDS = 1 V < 2 V: triode, ID = 1 × [2(2)(1) − 1] = 3 mA. VDS = 4 V ≥ 2 V: saturation, ID = 1 × 22 = 4 mA.

Check 3. (a) VGS = VDS = 12 − 4ID. ID = 0.5(10 − 4ID)2 gives 8ID2 − 41ID + 50 = 0: ID = 2 or 3.125 mA. The second gives VGS = −0.5 V: reject. ID = 2 mA, VGS = VDS = 4 V. (b) VGS = 0, so ID = IDSS = 12 mA; VDS = 18 − 12 × 0.62 = 10.56 V (sheet: 10.6 V). (c) VGS = −IDRS is negative; an n-channel E-MOSFET needs VGS > VT > 0.

Check 4. (a) Rin = 1/gm = 500 Ω. (b) Av = 2/(1 + 2) = 0.667. (c) gm = 2√(0.5 × 8) = 4 mS: four times the current, twice the gm.

Self-test.

  1. See step 1: positive gate repels holes, attracts electrons; at VT an n-type inversion layer joins source and drain.
  2. ID = 0.25 × 42 = 4 mA; gm = 2 × 0.25 × 4 = 2 mS.
  3. 2.5 = 10(1 + VGS/8)2: 1 + VGS/8 = 0.5, so VGS = −4 V.
  4. VDS ≥ VGS − VT. The channel pinches off at the drain end; extra VDS drops across the short pinched region, so the channel voltage and current stay fixed.
  5. Av = −4 × 2/(1 + 4 × 0.5) = −8/3 = −2.67.
  6. Channel built-in or induced; normally on or off; VGS polarity range (both signs vs above VT only); equation (Shockley vs K(VGS − VT)2); symbol (solid vs broken line); self-bias possible only for D-type.
