A diode (03a, 03b) has two terminals and no control. A transistor adds a third terminal that controls the current between the other two. The JFET is the simplest one: a reverse-biased pn junction squeezes a channel of doped silicon.

Build

1 · What a JFET is

Predict

The gate of a JFET is a pn junction that is always kept reverse biased. How much current flows into the gate?

Terms

Channel: the strip of n-type silicon the current flows through. Source, drain: its two ends; carriers enter at the source and leave at the drain. Gate: the p regions on both sides of the channel, joined together.

  • Making VGS more negative widens the depletion regions, which narrows the channel, so the drain current ID falls.
  • At VGS = VGS(off) the depletion regions meet and ID = 0 (cutoff).
  • With VGS = 0, raising VDS pinches the channel at the drain end. Above the pinch-off voltage VP the current stops rising and stays at IDSS, the largest current the JFET carries. Numerically VP = |VGS(off)|.

Answer. Only a leakage current of nanoamps (IG ≈ 0), because the gate junction is reverse biased. So the input resistance is very high (108–1012 Ω), and the drain current is controlled by a voltage, not a current. One type of carrier does the work, so the JFET is unipolar.

Check 1

(a) What two things does making VGS more negative do inside the device? (b) Define IDSS and VGS(off). (c) Why is the depletion region wider at the drain end than at the source end?

2 · Shockley's equation

Step 1 says ID falls as VGS goes negative. The next question is by how much.

Sheet Q2

A JFET has IDSS = 32 mA, VGS(off) = −8 V and VGS = −4.5 V. Find the value of drain current.

Guess first

VGS is a little over halfway to cutoff. Is ID more or less than half of IDSS?

In saturation the transfer curve is a parabola:

ID = IDSS(1 − VGS/VGS(off))2

Quick sketch points: VGS = 0 gives IDSS; VGS = VGS(off)/2 gives IDSS/4; VGS = VGS(off) gives 0. Both voltages are negative for an n-channel JFET, so the ratio is positive.

Region Condition Behaviour
Ohmic VDS < VGS − VGS(off) a resistor whose value VGS sets
Saturation VDS ≥ VGS − VGS(off) ID fixed by VGS alone; amplifiers work here
Cutoff VGS ≤ VGS(off) ID = 0

Answer. ID = 32 × (1 − (−4.5)/(−8))2 = 32 × 0.43752 = 6.12 mA, under a fifth of IDSS: the square makes the current fall fast.

(a) Sheet Q5 VGS = −2 V, VGS(off) = −6 V, IDSS = 3 mA. Find ID. (b) Sheet Q3 ID = 5 mA, IDSS = 10 mA, VGS(off) = −6 V. Find VGS and VP.

3 · The parameters gm, rd, μ

ID depends on two voltages, VGS and VDS. Each slope of that dependence is a parameter, and this is the item flagged at 8 marks.

Deck slides 30–31 · 8 marks

Define the characteristic parameters of a JFET and derive the relation among them.

Guess first

How many independent slopes can you take of a quantity that depends on two variables?

Parameter Definition Held constant Meaning, unit
Transconductance gm ΔID/ΔVGS VDS how strongly the gate controls ID; S (mS, μS)
Drain resistance rd ΔVDS/ΔID VGS AC resistance of the channel in saturation; kΩ–MΩ
Drain conductance gd ΔID/ΔVDS = 1/rd VGS slope of a drain curve; S
Amplification factor μ −ΔVDS/ΔVGS ID volts of VDS that undo 1 V of VGS; no unit

Answer (derivation). For small changes, ΔID = (∂ID/∂VGS)ΔVGS + (∂ID/∂VDS)ΔVDS = gmΔVGS + ΔVDS/rd. Hold ID constant (ΔID = 0): gmΔVGS = −ΔVDS/rd, so −ΔVDS/ΔVGS = gmrd. The left side is μ by definition:

μ = gm × rd

gm from Shockley. Differentiating step 2's equation:

gm = gm0(1 − VGS/VGS(off))   gm0 = 2IDSS/|VGS(off)|

Example: IDSS = 8 mA, VGS(off) = −4 V gives gm0 = 4 mS; at VGS = −2 V, gm = 2 mS. With rd = 50 kΩ, μ = 2 mS × 50 kΩ = 100.

4 · Self-bias

To use a JFET, it must sit at a fixed point (ID, VDS) in saturation. Choosing the resistors that put it there is biasing.

practice

A self-biased JFET has IDSS = 8 mA, VGS(off) = −4 V, RS = 1 kΩ, RD = 3.3 kΩ and VDD = 20 V. Find ID, VGS and VDS.

Guess first

The gate is tied to ground through RG. How can VGS be negative with no negative supply?

Two facts make every JFET bias problem short: IG = 0, so there is no drop across RG and VG = 0; and IS = ID. The source sits at IDRS above ground, so VGS = −IDRS. If ID rises, VGS becomes more negative and pulls it back: the circuit corrects itself.

Answer. Put VGS = −ID (mA, kΩ) into Shockley: ID = 8(1 − ID/4)2, which gives ID2 − 10ID + 16 = 0, so ID = 2 mA or 8 mA. Reject 8 mA: it needs VGS = −8 V, beyond cutoff. So ID = 2 mA, VGS = −2 V, and VDS = 20 − 2(3.3 + 1) = 11.4 V. Saturation check: 11.4 ≥ VGS − VGS(off) = 2 V ✓.

Check 4

(a) Why does self-bias always give two roots, and how do you pick the right one? (b) Sheet Q19 VDD = 20 V, RD = 500 Ω, no RS. Give the two end points of the d.c. load line.

5 · Voltage-divider bias

Self-bias depends strongly on the device's IDSS, which varies from part to part. A divider fixes the gate voltage instead.

Sheet Q17

Determine ID and VGS for the JFET with voltage-divider bias in Fig. 9, given that VD = 7 V. (Fig. 9: VDD = 12 V, RD = 3.3 kΩ, RS = 1.8 kΩ, R1 = 6.8 MΩ, R2 = 1 MΩ.)

Guess first

VD is given. Which single resistor lets you find ID straight away?

VG = VDDR2/(R1 + R2)   VGS = VG − IDRS   VDS = VDD − ID(RD + RS)

VGS must still come out negative. The drain-loop equation is the same for every bias circuit.

Answer. ID = (VDD − VD)/RD = (12 − 7)/3.3 k = 1.52 mA. VS = 1.52 mA × 1.8 kΩ = 2.73 V. VG = 12 × 1/(6.8 + 1) = 1.54 V. VGS = 1.54 − 2.73 = −1.19 V (the sheet rounds to −1.2 V).

Sheet Q18 An n-channel JFET with IDSS = 10 mA and VGS(off) = −5 V is biased by a divider with VDD = 30 V, R1 = 1 MΩ, R2 = 500 kΩ, to ID = 2.5 mA and VDS = 8 V. Find RS.

6 · JFET amplifiers

A biased JFET turns a small change in vgs into a change in id of gmvgs (step 3). A drain resistor turns that current into an output voltage.

practice

A common-source amplifier has gm = 2 mS, rd = 50 kΩ and RD = 2.2 kΩ, with RS fully bypassed. Find the voltage gain.

Guess first

Will the output be in phase with the input, or inverted?

Common source Common drain (source follower) Common gate
In · out gate · drain gate · source source · drain
Av −gm(rd ∥ RD); unbypassed: −gmRD/(1 + gmRS) gmRS/(1 + gmRS), just under 1 +gmRD
Phase inverted in phase in phase
Zin RG, very high RG, very high RS ∥ 1/gm, low
Zout ≈ RD RS ∥ 1/gm, low ≈ RD
Used as voltage amplifier buffer high-frequency stage

Answer. rd ∥ RD = (50 × 2.2)/52.2 = 2.107 kΩ, so Av = −2 mS × 2.107 kΩ = −4.21. Inverted: a rise in vgs raises id, which drops more voltage across RD, so the drain falls.

Check 6

(a) A source follower has gm = 2 mS, RS = 1 kΩ. Find Av and Zout. (b) What happens to the CS gain if CS is removed, and why? (c) Which configuration goes between a 1 MΩ sensor and a 1 kΩ load?

Exam form

Operation. n-channel bar, two p-gate regions; gate reverse biased, so IG ≈ 0 and Zin is very high. More negative VGS → wider depletion → narrower channel → less ID. Cutoff at VGS(off); pinch-off at VP = |VGS(off)|, where ID levels at IDSS. Unipolar, voltage-controlled.

Shockley. ID = IDSS(1 − VGS/VGS(off))2; saturation if VDS ≥ VGS − VGS(off).

Parameters (8 marks). Table of gm, rd, gd, μ with what is held constant → ΔID = gmΔVGS + ΔVDS/rd → set ΔID = 0 → μ = gmrd. Add gm = gm0(1 − VGS/VGS(off)), gm0 = 2IDSS/|VGS(off)|.

Bias procedure. 1. Gate loop: VGS = −IDRS (self) or VG − IDRS (divider). 2. Put it into Shockley, solve the quadratic. 3. Reject the root beyond cutoff. 4. VDS = VDD − ID(RD + RS). 5. Check saturation.

Amplifiers. CS: −gm(rd ∥ RD), inverted. CD: gmRS/(1 + gmRS), Zout = RS ∥ 1/gm. CG: +gmRD, Zin low.

Applications. Low-noise high-Zin first stage, buffer, voltage-variable resistor (ohmic region), analog switch, constant-current source.

Traps

  • Dropping the minus signs: for n-channel, VGS and VGS(off) are both negative, and their ratio is positive.
  • Keeping the root beyond cutoff after solving the self-bias quadratic.
  • Skipping the saturation check at the end.
  • Putting a voltage drop across RG: IG = 0.
  • Using −gmRD when RS is unbypassed: the gain falls to −gmRD/(1 + gmRS).
  • Writing VP with a sign: VP is the magnitude of VGS(off).

Self-test

  1. Why is a JFET called voltage-controlled and unipolar?
  2. Sheet Q4 VGS(off) = −4 V, IDSS = 12 mA, RD = 560 Ω, gate tied to source. Find the minimum VDD for the constant-current region.
  3. Sheet Q6 A reverse gate voltage of 15 V gives a gate current of 10−3 μA. Find the resistance between gate and source.
  4. Write μ = gmrd starting from ΔID = 0, from memory.
  5. Find gm0 for IDSS = 8 mA, VGS(off) = −4 V, and gm at VGS = −1 V.

Answers

Check 1. (a) Widens the gate depletion regions, so the channel narrows; channel resistance rises and ID falls. (b) IDSS: the drain current in saturation with VGS = 0, the maximum. VGS(off): the VGS at which ID becomes zero. (c) The channel voltage rises from source to drain, so the gate junction is more reverse biased near the drain.

Check 2. (a) ID = 3(1 − 2/6)2 = 3 × 0.444 = 1.33 mA. (b) 5 = 10(1 + VGS/6)2, so 1 + VGS/6 = √0.5 = 0.707 and VGS = −1.76 V; VP = 6 V.

Check 3. (a) gm = 0.3 mA/0.1 V = 3 mS (3000 μS). (b) gm = 4000 × (1 − 3/8) = 2500 μS.

Check 4. (a) Shockley is a square, so the gate-loop line crosses the parabola twice. The root with |VGS| larger than |VGS(off)| is beyond cutoff, where the equation does not apply: reject it. (b) ID = 0 gives VDS = VDD = 20 V; VDS = 0 gives ID = 20/0.5 k = 40 mA.

Check 5. Shockley: 2.5 = 10(1 + VGS/5)2, so VGS = −2.5 V. VG = 30 × 500/1500 = 10 V. VS = VG − VGS = 12.5 V. RS = 12.5 V/2.5 mA = 5 kΩ.

Check 6. (a) Av = 2/(1 + 2) = 0.667; Zout = 1 kΩ ∥ 500 Ω = 333 Ω. (b) It falls to −gmRD/(1 + gmRS): the signal current now flows through RS, and the voltage there subtracts from vgs (negative feedback, 13). (c) Common drain: very high Zin, low Zout.

Self-test.

  1. ID is set by the gate voltage through the depletion width, with no gate current. One carrier type (electrons in n-channel) carries the current.
  2. Constant current needs VDS ≥ VP = 4 V with ID = IDSS = 12 mA. VDD = 4 + 12 mA × 560 Ω = 10.72 V.
  3. R = 15 V/10−9 A = 1.5 × 1010 Ω (15 000 MΩ).
  4. See step 3's derivation.
  5. gm0 = 2 × 8/4 = 4 mS; gm = 4 × (1 − 1/4) = 3 mS.
  6. Any three: low-noise high-input-impedance amplifier, buffer, voltage-variable resistor, analog switch or chopper, constant-current source.
