The JFET

A diode has two terminals and no control. A transistor adds a third terminal that controls the current between the other two. The JFET is the simplest one to understand: a reverse-biased pn junction (Part B) squeezes a channel of doped silicon (Part A).

C1 · Construction and operation

Practice · JFET deck slides 5–16 Why is a JFET called a voltage-controlled device, and why is its input resistance so high?
Guess first: the gate junction is reverse biased. How much gate current flows?
Channel: the strip of n-type silicon that current flows through. · Source, Drain: the two ends of the channel; carriers enter at the source and leave at the drain. · Gate: the p regions on both sides of the channel, joined together.
{{ jfet_struct() }}

Construction (n-channel). A bar of n-type silicon with a contact at each end (source and drain). Two heavily doped p regions are diffused into its sides and wired together as the gate. Each p region forms a pn junction with the channel, and every junction has a depletion region (B1).

Operation. The gate is always reverse biased (VGS ≤ 0 for n-channel). Making VGS more negative widens the depletion regions (B1), which narrows the channel and raises its resistance, so the drain current ID falls. At VGS = VGS(off) the depletion regions meet, the channel is closed and ID = 0.

Pinch-off. With VGS = 0, raise VDS. The drain end of the channel is more positive than the source end, so the reverse bias, and the depletion region, is widest near the drain. At VDS = VP, the pinch-off voltage, the regions almost touch at the drain end. Beyond this the current stops rising and stays at IDSS: the drain-to-source saturation current, which is the largest current the JFET can carry. Numerically VP = |VGS(off)|.

p-channel: swap n and p, reverse every voltage and current direction; holes carry the current.

Answer. The drain current is set by the gate voltage VGS through the width of the depletion regions; no gate current is needed. The gate junction is reverse biased, so only a leakage current of nanoamps flows (IG ≈ 0). Input resistance = VGS/IG is therefore very high, 10⁸–10¹² Ω. Also, only one type of carrier takes part (electrons in an n-channel device), so the JFET is a unipolar device.

C2 · Characteristics and Shockley's equation

Professor's JFET numericals sheet · Q2 A JFET has the following parameters: IDSS = 32 mA; VGS(off) = −8 V; VGS = −4.5 V. Find the value of drain current.
Guess first: VGS is a little over halfway to cutoff. Is ID more or less than half of IDSS?
{{ jfet_curves() }}

Drain curves (right): ID against VDS, one curve per VGS. Four regions:

RegionCondition (n-channel)Behaviour
OhmicVDS < VGS − VGS(off)ID rises with VDS. The channel is a resistor whose value is set by VGS (a voltage-variable resistor).
Saturation (pinch-off, active)VDS ≥ VGS − VGS(off)ID is constant, set only by VGS. Amplifiers work here.
CutoffVGS ≤ VGS(off)ID = 0.
BreakdownVDS too largeThe gate junction avalanches; ID shoots up.

Transfer curve (left): ID against VGS in saturation. It is a parabola, given by Shockley's equation:

ID = IDSS(1 − VGS/VGS(off))²

Quick points for sketching it: VGS = 0 → IDSS. VGS = VGS(off)/2 → IDSS/4. VGS = VGS(off) → 0. Keep the signs: for an n-channel JFET both VGS and VGS(off) are negative, so the ratio is positive.

Answer. ID = 32 × (1 − (−4.5)/(−8))² = 32 × (0.4375)² = 6.12 mA. That is under a fifth of IDSS: the square makes the current fall quickly.

C3 · The characteristic parameters: gm, rd, gd, μ

Professor's JFET deck · slides 30–31 "Characteristics parameters of JFET" · a classmate's relay says 8 marks Define the characteristic parameters of a JFET and derive the relation among them.
Guess first: ID depends on two voltages. How many independent slopes can you define?
ParameterDefinitionHeld constantMeaning · unit
Transconductance (mutual conductance) gmgm = ΔID/ΔVGSVDSHow strongly the gate voltage controls the drain current. Slope of the transfer curve. Siemens (mS, μS; also written mho).
Drain resistance rdrd = ΔVDS/ΔIDVGSAC resistance of the channel in saturation. Inverse slope of a drain curve. Tens of kΩ to MΩ.
Drain conductance gdgd = ΔID/ΔVDS = 1/rdVGSSlope of a drain curve. Siemens.
Amplification factor μμ = −ΔVDS/ΔVGSIDHow many volts of VDS are needed to undo 1 V of VGS. No unit.
Derivation of μ = gm rd. ID is a function of VGS and VDS. For small changes (Taylor's theorem, first-order terms):

ΔID = (∂ID/∂VGS)ΔVGS + (∂ID/∂VDS)ΔVDS = gmΔVGS + ΔVDS/rd

Hold ID constant, so ΔID = 0: gmΔVGS = −ΔVDS/rd. Therefore −ΔVDS/ΔVGS = gmrd, and by definition the left side is μ:

μ = gm × rd

gm from Shockley's equation. Differentiate ID = IDSS(1 − VGS/VGS(off))² with respect to VGS:

gm = gm0(1 − VGS/VGS(off))     gm0 = 2IDSS/|VGS(off)|     gm = gm0√(ID/IDSS)

gm0 is the value at VGS = 0, the largest gm the device has. gm falls in a straight line to zero at cutoff. Example: IDSS = 8 mA, VGS(off) = −4 V gives gm0 = 4 mS; at VGS = −2 V, gm = 2 mS. With rd = 50 kΩ, μ = 2 mS × 50 kΩ = 100.

C4 · Biasing the JFET

Professor's JFET numericals sheet · Q17 Determine ID and VGS for the JFET with voltage-divider bias in Fig. 9, given that VD = 7 V.
Guess first: which single resistor lets you find ID straight away?
Biasing: choosing the DC voltages and resistors so the transistor sits at a wanted Q-point (ID, VDS) in saturation. · VG, VS, VD: voltages from each terminal to ground. VGS = VG − VS.
{{ jfet_divider() }}{{ jfet_self_bias() }}

Two facts make every JFET bias problem short: IG = 0, so no current and no voltage drop in the gate resistor, and IS = ID.

CircuitGate-source loopNotes
Fixed biasVGS = −VGGA separate negative supply sets VGS directly. Then Shockley gives ID. Needs two supplies.
Self-bias (right)VG = 0, VS = IDRS, so VGS = −IDRSThe drop across RS makes the source positive, which is the same as making the gate negative. One supply. If ID rises, VGS gets more negative and pulls it back: self-correcting.
Voltage divider (left)VG = VDDR2/(R1 + R2), VGS = VG − IDRSMost stable Q-point. VGS must still come out negative.

In every case the drain loop gives VDS = VDD − ID(RD + RS).

Worked self-bias (right-hand circuit, IDSS = 8 mA, VGS(off) = −4 V). Put VGS = −IDRS = −ID (mA, kΩ) into Shockley: ID = 8(1 − ID/4)², which rearranges to ID² − 10ID + 16 = 0, so ID = 2 mA or 8 mA. Reject 8 mA: it would need VGS = −8 V, beyond cutoff. So ID = 2 mA, VGS = −2 V, VDS = 20 − 2(3.3 + 1) = 11.4 V. Saturation check: 11.4 ≥ VGS − VGS(off) = 2 V ✓.

Answer (Q17). VD is given, so use RD: ID = (VDD − VD)/RD = (12 − 7)/3.3 k = 1.52 mA. VS = IDRS = 1.52 mA × 1.8 kΩ = 2.73 V. VG = 12 × 1/(6.8 + 1) = 1.54 V. VGS = 1.54 − 2.73 = −1.19 V (the sheet rounds to −1.2 V).

C5 · Small-signal model and JFET amplifiers

Practice · JFET deck slides 35–44 A common-source JFET amplifier has gm = 2 mS, rd = 50 kΩ and RD = 2.2 kΩ, with the source resistor fully bypassed. Find the voltage gain.
Guess first: will the output be in phase with the input or inverted?
Coupling capacitor (C1, C2): passes the AC signal, blocks DC, so the bias is not disturbed. · Bypass capacitor (CS): shorts RS for AC so it does not reduce the gain. · AC equivalent circuit: capacitors and DC supplies replaced by short circuits.

Why CS inverts: a rise in vgs raises id, which drops more voltage across RD, so the drain voltage falls.

Applications of the JFET: low-noise, high-input-impedance amplifier (first stage of instruments and receivers), buffer, voltage-variable resistor (ohmic region), analog switch and chopper, constant-current source (VGS = 0 gives IDSS).

Answer. rd ∥ RD = (50 × 2.2)/(52.2) = 2.107 kΩ. Av = −gm(rd ∥ RD) = −2 mS × 2.107 kΩ = −4.21. The minus sign means the output is inverted.
