# exam-pack/ — drop PYQs & PPTs here

Put the **downloaded MUJ exam material** for this subject in this folder:
- Previous year question papers (**MTE** and **ETE**) — PDFs.
- Course **PPTs** / lecture slides.
- A `links.md` with portal/Drive URLs if you prefer not to download.

Get them from the student portals listed in `../../research-engine/exam-resources.md`
(MUJ Central, MUJ Stella, MUJ Toppers, etc.). The research engine ingests whatever is here when it
builds this subject's Stage 1, and turns it into `knowledge-base/exam-map.md` (topic weightage +
question patterns).

**Honesty rule (from exam-resources.md):** these files tell us *what is tested and how* (trust them
for that) — they do **not** set facts (answer keys/notes can be wrong; content is verified against
the prescribed textbooks). Empty folder = the engine proceeds syllabus-driven and flags the
exam-targeting as unconfirmed.
