Experiment 1 — Pointers

Aim

To write a program in C++ to implement pointers: store the address of a variable in a pointer and access the variable through the pointer.

Theory

A pointer is a variable that stores the memory address of another variable. The address-of operator & gives the address of a variable, and the dereference operator * gives the value stored at the address held in a pointer. If ptr = &number, then ptr holds the address of number, and *ptr gives the value of number. Pointers are the basis of dynamic memory allocation, passing arguments by reference, and linked structures such as linked lists, trees and graphs. Time complexity O(1), space complexity O(1).

Algorithm

  1. Start.
  2. Declare an integer variable number = 25.
  3. Declare an integer pointer ptr.
  4. Store the address of number in ptr (ptr = &number).
  5. Display the value of number and its address &number.
  6. Display the address stored in ptr and the value *ptr.
  7. Stop.

Flowchart

flowchart TD
A(["Start"]) --> B["number = 25"]
B --> C["Declare pointer ptr"]
C --> D["ptr = #amp;number"]
D --> E[/"Print number, #amp;number"/]
E --> F[/"Print ptr, *ptr"/]
F --> G(["Stop"])

Program

e01_pointers.cpp
#include <iostream>
using namespace std;

int main()
{
    int number = 25;
    int *ptr;              // ptr can hold the address of an int

    ptr = &number;         // & = "address of"

    cout << "Value of number = " << number << endl;
    cout << "Address of number = " << &number << endl;
    cout << "Pointer stores = " << ptr << endl;
    cout << "Value using pointer = " << *ptr << endl;   // * = "value at"

    return 0;
}

Result

The program was executed successfully. The pointer stored the address of number (the same value as &number), and dereferencing it (*ptr) gave the value 25.

Experiment 2 — Pointer arithmetic

Aim

To write a program in C++ to implement pointer arithmetic by performing increment, decrement and addition operations on a pointer.

Theory

Arithmetic on a pointer moves it in units of the data type it points to, not in bytes. For an int pointer (4-byte int), ptr++ moves to the next element (address + 4), ptr-- moves back one element, and ptr + 2 moves two elements forward (address + 8). This works because array elements are stored in contiguous memory. The array name is the address of its first element (arr == &arr[0]), and *(ptr + i) is equivalent to arr[i]. Pointer arithmetic is used for array traversal and in dynamic data structures. Time complexity O(1), space complexity O(1).

Algorithm

  1. Start.
  2. Declare an integer array arr[5] = {10, 20, 30, 40, 50}.
  3. Declare a pointer ptr and point it to the first element (ptr = arr).
  4. Display the address in ptr and the value *ptr.
  5. Increment the pointer (ptr++); display the address and value.
  6. Decrement the pointer (ptr--); display the address and value.
  7. Add 2 to the pointer (ptr = ptr + 2); display the address and value.
  8. Stop.

    cout << "Value : " << *ptr << endl;

    cout << "\nAfter Adding 2" << endl;
    cout << "Address : " << ptr << endl;
    cout << "Value : " << *ptr << endl;

    return 0;
}

Experiment 3 — Insertion in an array (beginning, any position, end)

Aim

To write a program in C++ to insert an element into an array at the beginning, at any specified position, and at the end.

Theory

An array stores elements in contiguous memory locations, so a gap must be created before a new element can be inserted. To create the gap, elements are shifted one place to the right, starting from the last element so that no value is overwritten before it is moved.

  • Beginning: all n elements shift right; the new element goes to index 0. O(n).

  • Any position (1 to n+1): elements from index pos−1 onward shift right; the new element goes to index pos−1. O(n).

  • End: the new element goes to index n; no shifting. O(1).

After insertion, the number of elements n increases by 1. Insertion is not possible when the array is full (overflow). Space complexity O(1).

Algorithm

  1. Start.
  2. Declare arr[100]; read n and the n elements.
  3. If n ≥ 100, display "Array is full" and stop.
  4. Display the menu and read the choice.
  5. If choice = 1 (beginning): read value; for i = n down to 1, set arr[i] = arr[i−1]; set arr[0] = value.
  6. If choice = 2 (position): read pos; if pos < 1 or pos > n+1, display "Invalid position" and stop; read value; for i = n down to pos, set arr[i] = arr[i−1]; set arr[pos−1] = value.
  7. If choice = 3 (end): read value; set arr[n] = value.
  8. Set n = n + 1.
  9. Display the updated array.
  10. Stop.

#include <iostream>
using namespace std;

int main()
{
    int arr[100], n, value, pos, choice;

    cout << "Enter number of elements: ";
    cin >> n;

    cout << "Enter array elements:\n";
    for (int i = 0; i < n; i++)
        cin >> arr[i];

    if (n >= 100)
    {
        cout << "Array is full. Insertion not possible.";
        return 0;
    }

    cout << "\n1. Insert at Beginning";
    cout << "\n2. Insert at Any Position";
    cout << "\n3. Insert at End";
    cout << "\nEnter your choice: ";
    cin >> choice;

    if (choice == 1)
    {
        cout << "Enter value: ";
        cin >> value;

        for (int i = n; i > 0; i--)          // shift right, last element first
            arr[i] = arr[i - 1];

        arr[0] = value;
        n++;
    }
    else if (choice == 2)
    {
        cout << "Enter Position: ";
        cin >> pos;

        if (pos < 1 || pos > n + 1)
        {
            cout << "Invalid position.";
            return 0;
        }

        cout << "Enter Value: ";
        cin >> value;

        for (int i = n; i >= pos; i--)       // shift right from the end down to pos
            arr[i] = arr[i - 1];

        arr[pos - 1] = value;                // position 3 = index 2
        n++;
    }
    else if (choice == 3)
    {
        cout << "Enter Value: ";
        cin >> value;

        arr[n] = value;                      // first free slot is index n
        n++;
    }
    else
    {
        cout << "Invalid choice.";
        return 0;
    }

    cout << "\nUpdated Array:\n";
    for (int i = 0; i < n; i++)
        cout << arr[i] << " ";

    return 0;
}

Experiment 4 — Deletion from an array (beginning, any position, end)

Aim

To write a program in C++ to delete an element from an array at the beginning, at any specified position, and at the end.

Theory

Deleting an element from an array leaves a gap, which is closed by shifting the following elements one place to the left, starting just after the deleted element.

  • Beginning: elements 1 … n−1 shift left. O(n).

  • Any position (1 to n): elements after index pos−1 shift left. O(n).

  • End: no shifting; only n is reduced. O(1).

After deletion, n decreases by 1. Deletion from an empty array is not possible (underflow). Space complexity O(1).

Algorithm

  1. Start.
  2. Declare arr[100]; read n and the n elements.
  3. If n ≤ 0, display "Array is empty" and stop.
  4. Display the menu and read the choice.
  5. If choice = 1 (beginning): display arr[0]; for i = 0 to n−2, set arr[i] = arr[i+1].
  6. If choice = 2 (position): read pos; if pos < 1 or pos > n, display "Invalid position" and stop; display arr[pos−1]; for i = pos−1 to n−2, set arr[i] = arr[i+1].
  7. If choice = 3 (end): display arr[n−1].
  8. Set n = n − 1.
  9. Display the updated array.
  10. Stop.

Experiment 5 — Matrix multiplication using modular programming

Aim

To write a program in C++ to implement matrix multiplication using modular programming, with separate functions for input, multiplication and display.

Theory

A matrix of order m × n has m rows and n columns. Two matrices A (r1 × c1) and B (r2 × c2) can be multiplied only if c1 = r2; the product C = A × B has order r1 × c2. Each element is the sum of products of a row of A with a column of B:

C[i][j] = Σk=0c1−1 A[i][k] × B[k][j]

This needs three nested loops, so the time complexity is O(r1 × c1 × c2), i.e. O(n³) for n × n matrices; the result needs O(r1 × c2) space. In modular programming the program is divided into functions that each do one task: inputMatrix(), multiplyMatrix(), displayMatrix(), with main() controlling execution. This makes the program easier to understand, debug and reuse.

Algorithm

  1. Start.
  2. Declare matrices A, B, C of size 10 × 10.
  3. Read the order r1 × c1 of A and r2 × c2 of B.
  4. If c1 ≠ r2, display "Matrix multiplication not possible" and stop.
  5. Call inputMatrix() to read A and then B.
  6. Call multiplyMatrix(): for each i (0 to r1−1) and j (0 to c2−1), set C[i][j] = 0, then for k = 0 to c1−1 add A[i][k] × B[k][j] to C[i][j].
  7. Call displayMatrix() to display C (r1 × c2).
  8. Stop.

Program

e05_matrix_multiply.cpp
#include <iostream>
using namespace std;

// Function to input matrix elements
void inputMatrix(int matrix[][10], int rows, int cols)
{
    for (int i = 0; i < rows; i++)
        for (int j = 0; j < cols; j++)
            cin >> matrix[i][j];
}

// Function to multiply two matrices: C = A x B
void multiplyMatrix(int A[][10], int B[][10], int C[][10], int r1, int c1, int c2)
{
    for (int i = 0; i < r1; i++)              // each row of A
    {
        for (int j = 0; j < c2; j++)          // each column of B
        {
            C[i][j] = 0;
            for (int k = 0; k < c1; k++)      // walk along row i and column j
                C[i][j] = C[i][j] + A[i][k] * B[k][j];
        }
    }
}

// Function to display matrix
void displayMatrix(int matrix[][10], int rows, int cols)
{
    for (int i = 0; i < rows; i++)
    {
        for (int j = 0; j < cols; j++)
            cout << matrix[i][j] << " ";
        cout << endl;
    }
}

int main()
{
    int A[10][10], B[10][10], C[10][10];
    int r1, c1, r2, c2;

    cout << "Enter rows and columns of first matrix: ";
    cin >> r1 >> c1;

    cout << "Enter rows and columns of second matrix: ";
    cin >> r2 >> c2;

    if (r1 < 1 || c1 < 1 || r2 < 1 || c2 < 1 || r1 > 10 || c1 > 10 || r2 > 10 || c2 > 10)
    {
        cout << "Sizes must be between 1 and 10.";
        return 0;
    }

    // Check multiplication condition
    if (c1 != r2)
    {
        cout << "Matrix multiplication not possible.";
        return 0;
    }

    cout << "Enter elements of first matrix:\n";
    inputMatrix(A, r1, c1);

    cout << "Enter elements of second matrix:\n";
    inputMatrix(B, r2, c2);

    multiplyMatrix(A, B, C, r1, c1, c2);

    cout << "\nResultant Matrix:\n";
    displayMatrix(C, r1, c2);

    return 0;
}

Experiment 6 — Matrix transpose using modular programming

Aim

To write a program in C++ to find the transpose of a matrix using modular programming, with separate functions for input, transpose and display.

Theory

The transpose of a matrix is obtained by interchanging its rows and columns. If A has order m × n, its transpose T has order n × m, and

T[j][i] = A[i][j]

so row i of A becomes column i of T. Every element is visited once, so the time complexity is O(m × n); storing the transpose in a separate matrix needs O(m × n) space. The program is modular: inputMatrix(), transposeMatrix() and displayMatrix(), with main() calling them. The transpose is displayed with its rows and columns interchanged (cols × rows).

Algorithm

  1. Start.
  2. Declare matrices A and T of size 10 × 10.
  3. Read the number of rows and columns of A.
  4. Call inputMatrix() to read A.
  5. Call transposeMatrix(): for each i (0 to rows−1) and j (0 to cols−1), set T[j][i] = A[i][j].
  6. Call displayMatrix(A, rows, cols) to display the original matrix.
  7. Call displayMatrix(T, cols, rows) to display the transpose.
  8. Stop.

#include <iostream>

void inputMatrix(int matrix[][10], int rows, int cols)
{
    for (int i = 0; i < rows; i++)
        for (int j = 0; j < cols; j++)
            cin >> matrix[i][j];

void transposeMatrix(int A[][10], int T[][10], int rows, int cols)
{
    for (int i = 0; i < rows; i++)
        for (int j = 0; j < cols; j++)
            T[j][i] = A[i][j];               // row i becomes column i
}

// Function to display matrix
void displayMatrix(int matrix[][10], int rows, int cols)
{
    for (int i = 0; i < rows; i++)
    {
        for (int j = 0; j < cols; j++)
            cout << matrix[i][j] << " ";
        cout << endl;
    }
}

{
    int A[10][10], T[10][10];
    int rows, cols;

    cout << "Enter number of rows and columns of matrix: ";
    cin >> rows >> cols;

    if (rows < 1 || cols < 1 || rows > 10 || cols > 10)
    {
        cout << "Sizes must be between 1 and 10.";
        return 0;
    }

    cout << "Enter elements of matrix:\n";
    inputMatrix(A, rows, cols);

    transposeMatrix(A, T, rows, cols);

    cout << "\nOriginal Matrix:\n";
    displayMatrix(A, rows, cols);

    cout << "\nTranspose Matrix:\n";
    displayMatrix(T, cols, rows);            // rows and columns swap

    return 0;
}

Experiment 7 — Insertion sort and its performance

Aim

To write a program in C++ to sort an array of integers in ascending order using insertion sort and analyse its performance.

Theory

Insertion sort divides the array into a sorted part (initially the first element) and an unsorted part. In each pass the next element is taken as the key; elements of the sorted part greater than the key are shifted one place right, and the key is inserted into the gap. After n − 1 passes the array is sorted.

  • Best case (already sorted): n − 1 comparisons, O(n).

  • Average case (random order): about n²/4 comparisons/shifts, O(n²).

  • Worst case (reverse sorted): n(n − 1)/2 comparisons/shifts, O(n²).

  • Space: O(1). It is in-place, stable, comparison-based, and efficient for small or nearly sorted data.

Algorithm

  1. Start.
  2. Read n and the n elements of the array.
  3. For i = 1 to n − 1: a. key = arr[i], j = i − 1. b. While j ≥ 0 and arr[j] > key: arr[j+1] = arr[j], j = j − 1. c. arr[j+1] = key.
  4. Display the sorted array.
  5. Stop.

Program

e07_insertion_sort.cpp
#include <iostream>
using namespace std;

// Function to perform Insertion Sort
void insertionSort(int arr[], int n)
{
    for (int i = 1; i < n; i++)
    {
        int key = arr[i];                    // card picked up
        int j = i - 1;

        // Shift elements greater than key one position to the right
        while (j >= 0 && arr[j] > key)
        {
            arr[j + 1] = arr[j];
            j--;
        }

        arr[j + 1] = key;                    // drop the card in the gap
    }
}

// Function to display the array
void displayArray(int arr[], int n)
{
    for (int i = 0; i < n; i++)
        cout << arr[i] << " ";
    cout << endl;
}

int main()
{
    int n;
    int arr[100];

    cout << "Enter number of elements: ";
    cin >> n;

    if (n < 1 || n > 100)
    {
        cout << "n must be between 1 and 100.";
        return 0;
    }

    cout << "Enter elements of the array:" << endl;
    for (int i = 0; i < n; i++)
        cin >> arr[i];

    cout << "Original Array: ";
    displayArray(arr, n);

    insertionSort(arr, n);

    cout << "Sorted Array: ";
    displayArray(arr, n);

    return 0;

Experiment 8 — Quick sort and comparison with other sorting techniques

Aim

To write a program in C++ to sort an array of integers using quick sort and compare its performance with other sorting techniques (bubble sort, selection sort, insertion sort).

Theory

Quick sort uses divide and conquer. A pivot is chosen (here the last element). Partitioning places all elements smaller than the pivot on its left and the rest on its right, so the pivot reaches its final sorted position. Quick sort is then applied recursively to the left and right sub-arrays, until each has zero or one element.

  • Best / average case: O(n log n). The pivot splits the array into roughly equal parts, giving about log n levels of O(n) work each.

  • Worst case: O(n²). The pivot is always the smallest or largest element, e.g. already sorted input with the last-element pivot.

  • Space: O(log n) on average for the recursion (O(n) in the worst case). It is in-place but not stable.

Quick sort O(n log n) O(n log n) O(n²) O(log n)
Bubble sort O(n) O(n²) O(n²) O(1)
Selection sort O(n²) O(n²) O(n²) O(1)
Insertion sort O(n) O(n²) O(n²) O(1)

For a fair comparison, each algorithm sorts its own copy of the same input, and execution time is measured with clock().

Algorithm

  1. Start.
  2. Read n and the n elements into original[].
  3. For each of quick, bubble, selection and insertion sort: copy original[] into work[], sort work[], and display it.
  4. quickSort(arr, low, high): if low < high: pi = partition(arr, low, high); quickSort(arr, low, pi − 1); quickSort(arr, pi + 1, high).
  5. partition(arr, low, high): pivot = arr[high], i = low − 1; for j = low to high − 1: if arr[j] < pivot then i = i + 1 and swap arr[i], arr[j]. Finally swap arr[i+1], arr[high] and return i + 1.
  6. Fill original[] with 10 000 random numbers. For each algorithm: copy, record start = clock(), sort, record end = clock(), display (end − start) in ms.
  7. Stop.

#include <iostream>
#include <cstdlib>     // rand, srand
#include <ctime>       // clock, CLOCKS_PER_SEC
using namespace std;

const int BIG = 10000;                       // size used for the timing test

void swapElements(int &a, int &b)
{
    int temp = a;
    a = b;
    b = temp;
}

int partitionArray(int arr[], int low, int high)
{
    int pivot = arr[high];
    int i = low - 1;
    for (int j = low; j < high; j++)
        if (arr[j] < pivot)
        {
            i++;
            swapElements(arr[i], arr[j]);
        }
    swapElements(arr[i + 1], arr[high]);
    return i + 1;
}

void quickSort(int arr[], int low, int high)
{
    if (low < high)
    {
        int pi = partitionArray(arr, low, high);
        quickSort(arr, low, pi - 1);
        quickSort(arr, pi + 1, high);
    }
}

// Bubble Sort: neighbours swap until the largest "bubbles" to the end
void bubbleSort(int arr[], int n)
{
    for (int i = 0; i < n - 1; i++)
    {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++)
            if (arr[j] > arr[j + 1])
            {
                swapElements(arr[j], arr[j + 1]);
                swapped = true;
            }
        if (!swapped)                        // no swap in a pass = already sorted
            break;
    }
}

// Selection Sort: pick the smallest of the rest, put it at position i
void selectionSort(int arr[], int n)
{
    for (int i = 0; i < n - 1; i++)
    {
        int minIndex = i;
        for (int j = i + 1; j < n; j++)
            if (arr[j] < arr[minIndex])
                minIndex = j;
        swapElements(arr[i], arr[minIndex]);
    }
}

void insertionSort(int arr[], int n)
{
    for (int i = 1; i < n; i++)
    {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key)
        {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}

void copyArray(int source[], int dest[], int n)
{
    for (int i = 0; i < n; i++)
        dest[i] = source[i];
}

void displayArray(int arr[], int n)
{
    for (int i = 0; i < n; i++)
        cout << arr[i] << " ";
    cout << endl;
}

Experiment 10 — Queue using an array (enqueue, dequeue)

Aim

To write a program in C++ to implement a queue using an array and perform enqueue and dequeue operations.

Theory

A queue is a linear data structure in which insertion (enqueue) takes place at the rear and deletion (dequeue) at the front. It follows FIFO (First In, First Out). In an array implementation, front = rear = −1 means the queue is empty. Enqueue: on the first element set front = 0, then increment rear and store. Dequeue: remove the element at front; if it was the last element (front = rear), reset both to −1, else increment front. Overflow: rear = MAX − 1. Underflow: front = −1. Enqueue and dequeue are O(1), display is O(n), space O(MAX). In a linear queue, slots freed by dequeue are not reused; a circular queue removes this limitation. Applications: CPU and printer scheduling, buffering, breadth-first search.

Algorithm

  4. Dequeue: if front = −1, display "Queue Underflow"; else display queueArr[front]; if front = rear set front = rear = −1, else front = front + 1.
  5. Display: if front = −1, display "Queue is empty"; else print queueArr[front … rear].
  6. Repeat from step 2 until Exit is chosen.
  7. Stop.

Experiment 11 — Singly linked list (insertion, deletion, traversal)

Aim

To write a program in C++ to implement a singly linked list and perform insertion, deletion and traversal operations.

Theory

A linked list is a linear data structure whose elements (nodes) need not be in contiguous memory. Each node of a singly linked list has a data field and a next pointer holding the address of the next node; the last node's next is NULL. The first node is accessed through the head pointer (head = NULL means the list is empty). Nodes are created at run time with new and freed with delete, so the list grows and shrinks dynamically.

  • Insertion at end: traverse to the last node and link the new node. O(n).

  • Deletion at beginning: move head to the second node and free the first. O(1).

  • Traversal: visit nodes from head until NULL. O(n).

Space O(n). Traversal is only in the forward direction.

Algorithm

  1. Start. Define struct Node { int data; Node *next; }; head = NULL.
  2. Display the menu (Insert, Delete, Traverse, Exit) and read the choice.
  3. Insert (end): create newNode with data = value, next = NULL. If head = NULL, head = newNode; else temp = head, move temp until temp→next = NULL, then temp→next = newNode.
  4. Delete (beginning): if head = NULL, display "List is empty"; else temp = head, display temp→data, head = head→next, delete temp.
  5. Traverse: if head = NULL, display "List is empty"; else temp = head; while temp ≠ NULL, display temp→data and set temp = temp→next.
  6. Repeat from step 2 until Exit is chosen.
  7. Stop.

To write a program in C++ to implement a circular linked list and perform insertion, deletion and traversal operations.

Theory

A circular linked list is a linked list in which the last node points back to the first node (head) instead of NULL, so the nodes form a circle. A single node points to itself. The last node is identified by temp->next == head. Traversal starts at head and stops when it returns to head, so a do-while loop is used (the stop condition is already true at the start).

  • Insertion at end: find the last node, link it to the new node, and point the new node to head. O(n).

  • Deletion at beginning: find the last node, move head to the next node, and point the last node to the new head. O(n). A single node is deleted by setting head = NULL.

  • Traversal: O(n).

Space O(n). Types: circular singly and circular doubly linked lists. Applications: round-robin scheduling, multiplayer turns, repeating playlists.

Algorithm

  1. Start. Define struct Node { int data; Node *next; }; head = NULL.
  2. Display the menu (Insert, Delete, Traverse, Exit) and read the choice.
  3. Insert (end): create newNode with data = value. If head = NULL, head = newNode and newNode→next = head; else move temp from head until temp→next = head, then temp→next = newNode and newNode→next = head.
  4. Delete (beginning): if head = NULL, display "List is empty"; else if head→next = head, delete head and set head = NULL; else find last (last→next = head), temp = head, head = head→next, last→next = head, delete temp.
  5. Traverse: if head = NULL, display "List is empty"; else temp = head; do { display temp→data; temp = temp→next } while temp ≠ head.
  6. Repeat from step 2 until Exit is chosen.
  7. Stop.

Program

e12_circular_linked_list.cpp
#include <iostream>
using namespace std;

struct Node
{
    int data;
    Node *next;
};

Node *head = NULL;

// Insert at the end
void insert(int value)
{
    Node *newNode = new Node;
    newNode->data = value;

    if (head == NULL)
    {
        head = newNode;
        newNode->next = head;                // one node points to itself
    }
    else
    {
        Node *temp = head;
        while (temp->next != head)           // last node is the one pointing to head
            temp = temp->next;
        temp->next = newNode;
        newNode->next = head;                // close the circle
    }
    cout << value << " inserted into list." << endl;
}

// Delete from the beginning
void deleteNode()
{
    if (head == NULL)
    {
        cout << "List is empty." << endl;
    }
    else if (head->next == head)             // only one node
    {
        cout << head->data << " deleted from list." << endl;
        delete head;
        head = NULL;
    }
    else
    {
        Node *temp = head;
        Node *last = head;
        while (last->next != head)           // find the last node
            last = last->next;

        cout << head->data << " deleted from list." << endl;
        head = head->next;
        last->next = head;                   // last now points to the new head
        delete temp;
    }
}

void traverse()
{
    if (head == NULL)
    {
        cout << "List is empty." << endl;
    }
    else
    {
        Node *temp = head;
        cout << "Circular Linked List: ";
        do                                   // do-while: print head before testing
        {
            cout << temp->data << " ";
            temp = temp->next;
        } while (temp != head);
        cout << endl;
    }
}

int main()
{
    int choice, value;

    do
    {
        cout << "\n1. Insert" << endl;
        cout << "2. Delete" << endl;
        cout << "3. Traverse" << endl;
        cout << "4. Exit" << endl;
        cout << "Enter your choice: ";
        cin >> choice;

        if (choice == 1)
        {
            cout << "Enter value to insert: ";
            cin >> value;
            insert(value);
        }
        else if (choice == 2)
        {
            deleteNode();
        }
        else if (choice == 3)
        {
            traverse();
        }
        else if (choice == 4)
        {
            cout << "Program terminated." << endl;
        }
        else
        {
            cout << "Invalid choice!" << endl;
        }
    } while (choice != 4);

    return 0;
}

Result

The program was executed successfully. Inserting 10, 20 and 30 gave the circular list 10 → 20 → 30 → (back to 10); deleting from the beginning removed 10, leaving 20 → 30 → (back to 20). The last node always pointed back to head.
