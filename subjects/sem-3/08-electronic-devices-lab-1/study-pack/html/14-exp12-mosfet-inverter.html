What you already have:

  • From Exp 9, a FET's gate voltage controls its channel.
  • From Exp 5, a transistor can be a switch: cut-off = open, saturation = closed.
  • From digital electronics: NOT gate, logic 1 and logic 0.

Three terms first:

  • Enhancement nMOS: a MOSFET whose gate is insulated by oxide (so it draws no gate current). It has no channel at VGS = 0. A channel forms only when VGS > VTH (threshold voltage).
  • Inverter: a NOT gate. Input high gives output low, and input low gives output high.
  • VTC (voltage transfer characteristic): Vout plotted against Vin.
Manual Exp 12, aim

Analyse an inverter circuit using a MOSFET. Viva form: "Explain the two states of the circuit, and mark VOH, VOL, VIL, VIH and VM on the VTC."

Guess first

When the input is 0 V, is the MOSFET on or off? What is the output then?

How it works

Input MOSFET Current Output
0 V (logic 0), below VTH off (cut-off): no channel ID = 0, so no drop across the 1 kΩ Vout = VDD = 5 V (logic 1)
5 V (logic 1), above VTH on, fully (deep triode): the channel is a very low resistance (≈ 9 mΩ for this part) ID ≈ 5 V/1 kΩ = 5 mA Vout ≈ 5 mA × 9 mΩ ≈ 0 V (logic 0)

VTC terms:

Term Meaning
VOH / VOL output high / output low levels
VIL the highest input still read as 0. Where the VTC slope first reaches −1.
VIH the lowest input read as 1. Where the slope returns to −1.
VM switching threshold, where Vout = Vin
noise margins NML = VIL − VOL and NMH = VOH − VIH: how much noise an input can carry before the gate misreads it

Why it switches so low and so sharply: the FDR6580 is a power MOSFET. It conducts amps from a tiny gate overdrive, so just past VTH it already pulls the 5 mA that the 1 kΩ allows. The switch therefore happens right at VTH, far below VDD/2.

The manual's Fig 12.2 (with VIL ≈ 0.9 V and VIH ≈ 2.2 V) is a generic textbook VTC, not this part's.

Trap: Vth vs VM

The manual says "Vth is the inverter threshold voltage, which is Vdd/2". These are two different quantities:

  • VTH is the MOSFET's own turn-on voltage.
  • VM is the inverter's switching point (where Vout = Vin).

VM = VDD/2 is the design goal of a symmetric CMOS inverter. In this resistor-load circuit, VM ≈ 0.76 V.

Write in your record

Result: the output is inverted with respect to the input, with maximum voltage 5 V as logic 1 and minimum voltage ≈ 0 V as logic 0. (VTC: VIL = 0.53 V, VIH = 0.77 V, VM = 0.76 V.)

Theory for the record: the inverter is the basic digital gate; NAND, NOR and larger logic are built from the same idea. In the resistive-load nMOS inverter, an enhancement nMOS pulls the output down and a resistor pulls it up to VDD. For Vin < VTH the MOSFET is cut off, no current flows, and Vout = VDD (logic 1). For a high input the MOSFET conducts in the linear region and pulls the output close to 0 (logic 0). The VTC shows VOH, VOL and the transition region, with VIL and VIH at the unity-slope points and VM where Vout = Vin. Noise margins are NML = VIL − VOL and NMH = VOH − VIH. A drawback: current (and power) flows continuously when the output is low, which CMOS removes.

Check 1

(a) How much power does this inverter waste when its output is LOW? When HIGH? (b) Why does the MOSFET's gate draw no DC current? (c) What replaces the resistor in a CMOS inverter, and what does that fix?

Answers

Opening question. Input 0 V: the MOSFET is off, so no current flows and the output = 5 V. Input 5 V: the MOSFET is on and the output ≈ 0 V. VOH = 5 V, VOL ≈ 0, VIL = 0.53 V, VIH = 0.77 V, VM = 0.76 V.

Check 1. (a) LOW: 5 mA flows from the 5 V supply, so P = 5 V × 5 mA = 25 mW, nearly all in the resistor. HIGH: no current, so ≈ 0 W. (b) The gate is insulated from the channel by a thin oxide layer: a capacitor, which passes no DC. (c) A pMOS transistor (pull-up). Only one transistor is on in each state, so no DC current flows from VDD to ground. The static power becomes ≈ 0, and VOL is exactly 0.
