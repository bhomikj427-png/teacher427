Three terms first:

  • Regulator: a circuit that keeps Vo constant.
  • Line regulation: how much Vo moves when the input Vin changes. The "line" is the supply line.
  • Load regulation: how much Vo moves when the load current changes, i.e. when RL changes.
Manual Exp 2, aim

To use a zener diode for line and load regulation. Viva form: "Input rises from 14 V to 17 V and Vo rises by only 0.08 V. Where did the other 2.92 V go?"

Guess first

Answer before reading on. Hint: there are only two other parts, R1 and the zener.

How a zener regulates

KCL at the output node: the current through R1 splits between the zener and the load.

IR1 = Vin − VZR1 = IZ + IL
  • Vin rises: the extra current all goes into the zener. VZ barely moves (small rz), so Vo stays put and R1 absorbs the extra voltage. That is the answer to the question.
  • RL falls (more load current): the zener gives up current to the load. Vo holds as long as IZ stays above IZ(min).
  • If the load demands more than R1 can supply, IZ hits zero, the zener switches off, and Vo becomes an ordinary divider output that collapses.

Because the zener sits in parallel (shunt) with the load, this is called a shunt regulator.

Load regulation (Fig 2.2)

Do it (LTspice)

  2. Directives: .step param R 100 1100 100 and .op. Run.
  3. Plot V(vo). The x-axis is now R.
  4. No load: delete R2, run .op again, and read VNL.
  5. Choose a full-load point (e.g. R = 1 kΩ) and read VFL.

Smallest load that still regulates: R1 can pass at most (20 − 6.2)/1 kΩ = 13.8 mA. The load gets all of that only when IZ → 0, so RL(min) = 6.2 V / 13.8 mA ≈ 450 Ω. This matches the knee in the plot. Below 450 Ω the zener is off, and Vo = 20 × RL/(1000 + RL): at 100 Ω that is 1.82 V ✓.

Write in your record

Result: % line regulation = 2.8 % (14–17 V, RL = 1 kΩ); % load regulation = 0.81 % (no load → 1 kΩ, Vin = 20 V). Lower % = better regulation.

Theory for the record: a zener shunt regulator places a reverse-biased zener across the load, fed through a series resistor RS. In breakdown, the zener voltage is nearly constant, so changes in input voltage appear across RS, and changes in load current are absorbed by a change in zener current. Regulation holds while IZ(min) < IZ < IZ(max). RS is chosen so that IZ ≥ IZ(min) at minimum input and maximum load. Line regulation = ΔVo/ΔVin × 100 %; load regulation = (VNL − VFL)/VFL × 100 %.

Trap: an "unregulated" line plot

If Vo keeps rising with slope ½ all the way to 20 V, the zener is in backwards (forward-biased, clamping at about 0.7 V) or is the wrong part. If Vo sticks at about 0.7 V, it is definitely reversed. The cathode (bar) must face the output node.

Check 1

(a) Why does Vo in the line plot still creep up slightly (6.23 → 6.36 V) instead of staying perfectly flat? (b) With Vin = 20 V and RL = 1 kΩ, how much current does the zener carry? (c) What happens to IZ when the load is removed, and why is that the worst case for zener power?

Answers

Opening question. Across R1. The extra input raises the current through R1 (it flows on into the zener), so R1's voltage drop rises by about 2.92 V.

Check 1. (a) The zener has a dynamic resistance rz (Exp 1). More current through it means slightly more voltage: ΔV = rzΔIZ. (b) IR1 = (20 − 6.358)/1000 = 13.64 mA, IL = 6.358/1000 = 6.36 mA, so IZ = 13.64 − 6.36 = 7.28 mA. (c) All of R1's current then flows through the zener, its maximum, so IZ and PZ = VZIZ peak. Design must keep this below IZ(max).
