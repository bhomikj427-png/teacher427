Answers

  1. See each chapter's redrawn figure and part table.
  2. Vpp = 3 V, so Vp = 1.5 V and Vrms = 1.5/√2 = 1.06 V.
  3. rz = ΔVZ/ΔIZ in breakdown: the slope of the curve, not V/I at one point.
  4. A mix of tunnelling (Zener) and avalanche. Their temperature coefficients are opposite (− and +), so they nearly cancel.
  5. The series resistor R1. The extra current goes into the zener, and Vo barely moves.
  6. Line: ΔVo/ΔVin × 100. Load: (VNL − VFL)/VFL × 100.
  7. 3 + 0.7 = 3.7 V.
  8. A clipper reduces Vpp. A clamper keeps Vpp and shifts the DC level.
  9. RC ≫ T (= 1 ms). Here RC = 10 ms.
  10. Active: BE forward, BC reverse. Saturation: both forward. Cut-off: both reverse.
  11. hie = ΔVBE/ΔIB (input curve, VCE fixed). hre = ΔVBE/ΔVCE (IB fixed). hfe = ΔIC/ΔIB (output curves, VCE fixed). hoe = ΔIC/ΔVCE (one output curve, IB fixed).
  12. The emitter bypass CE. At high f, the transistor's internal junction capacitances (Miller effect) and stray capacitance shunt the signal.
  13. BW = fH − fL, between the frequencies where the gain is 0.707 × max = −3 dB (half power).
  14. A rising base voltage raises IC, which increases the drop across RC, so the collector voltage falls.
  15. Gain ≈ 1 (slightly less), in phase; input resistance high, output resistance low; used as a buffer.
  16. Current-series negative feedback. Gain becomes stable (independent of β), bandwidth widens, distortion and noise fall, input resistance rises.
  17. gm = ΔID/ΔVGS (VDS const), rd = ΔVDS/ΔID (VGS const), μ = −ΔVDS/ΔVGS (ID const) = (ΔVDS/ΔID) × (ΔID/ΔVGS) = rdgm.
  18. ID = IDSS(1 − VGS/VP)². IDSS = drain current at VGS = 0 in saturation. VP = the VGS at which ID → 0.
  19. Av = −gm(RD ∥ RL). The gate draws no current, so megohm resistors drop no voltage.
  20. |Aβ| ≥ 1 and loop phase 360°. f = 1/(2πRC√6).
  21. At the oscillation frequency, the three-section RC ladder attenuates the signal to 1/29.
  22. Input low: MOSFET off, output = VDD. Input high: MOSFET on, output ≈ 0. VM = the input voltage at which Vout = Vin.
  23. Gains multiply (dB add). Bandwidth shrinks.
  24. 1Meg (1M is milli). .ac.
