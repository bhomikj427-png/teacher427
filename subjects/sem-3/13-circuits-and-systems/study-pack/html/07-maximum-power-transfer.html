Build

Class p.16

For what value of load resistance will maximum power be delivered? Then: determine the total power delivered by the source.

Guess first

Make RL tiny, then huge. What happens to the load's power at each extreme? So where must the maximum be?

1 · Power in the load

From 06, every linear source network is VTh in series with RTh, so this circuit is already in that form. The load current and power:

IL = VThRTh + RL   PL = IL2 RL = VTh2 RL(RTh + RL)2

2 · The condition (class p.13–14 derivation)

Set dPLdRL = 0. Quotient rule:

dPLdRL = VTh2·(RTh + RL)2 − RL·2(RTh + RL)(RTh + RL)4 = 0

The numerator must be zero:

(RTh + RL)2 − 2RL(RTh + RL) = 0 ⇒ RTh2 + 2RThRL + RL2 − 2RThRL − 2RL2 = 0 ⇒ RTh2 = RL2
RL = RTh

(The negative root is not a resistance. The curve above shows it is a maximum, not a minimum.)

Answer, part 1: RL = RTh = 10 kΩ.

3 · Pmax, source power, efficiency

Put RL = RTh into PL:

Pmax = VTh24RTh

For the board circuit, at RL = 10 kΩ:

Quantity Working Value
Current 10 V / 20 kΩ 0.5 mA
Total power from the source V·I = 10 × 0.5 mA 5 mW
Power in the load I2RL = (0.5 mA)2 × 10 kΩ = VTh2/4RTh 2.5 mW
Power in RTh same current, same resistance 2.5 mW
Efficiency η Pload / Ptotal = 2.5 / 5 50 %
Voltage across the load 0.5 mA × 10 kΩ 5 V = Vs/2
Load vs source VL = Vs/2, PL = Ps/2
Class p.16

The notes read "I × V = 0 5 mW" with no visible decimal point. The value is 5 mW. The 50 % efficiency on p.17 is right either way.

Maximum power is not maximum efficiency. η = RLRTh + RL keeps rising as RL grows (bottom plot), while PL falls. So:

  • communication / signal circuits match RL = RTh: a weak signal needs every bit of power delivered, and 50 % loss is acceptable;
  • power systems keep RL ≫ RTh: wasting half the generated power would be unacceptable.

The 50 % refers to the Thévenin equivalent. The power actually lost inside the original, full network can differ.

4 · AC loads: the conjugate match

Predict

A source has ZTh = 3 + j4 Ω. Its reactance j4 Ω doesn't absorb power, but it does limit the current. What reactance should the load add?

For impedances (class p.16; set 2 p.14: "ZL = ZTh*, * = complex conjugate, i → −i"):

ZL = ZTh*   (the complex conjugate: j → −j)
  • RL = RTh: the resistance match, as before.
  • XL = −XTh: the load's reactance cancels the source's, so the loop is purely resistive and the current is as large as possible.

For the Predict: ZL = 3 − j4 Ω. Then Pmax = |VTh|24RTh, with VTh as an rms value (with a peak value it is |VTh|28RTh).

textbook

The AC network of 06 §6 has VTh = 7.07∠−45° V (peak) and ZTh = 500 − j500 Ω. Find the load for maximum power, and that power.

  • Load: ZL = ZTh* = 500 + j500 Ω (500 Ω with an inductive reactance of 500 Ω; at ω = 1000 that is L = 0.5 H).
  • Loop: ZTh + ZL = 1000 Ω, purely resistive: the reactances cancel. I = 7.071000 = 7.07 mA peak = 5 mA rms.
  • Power: P = Irms2RL = (5 mA)2 × 500 Ω = 12.5 mW. Same by formula: Vrms = 5 V, 254 × 500 = 12.5 mW.

A computer sweep over every load R + jX gives its peak at exactly R = 500 Ω, X = +500 Ω, 12.5 mW.

Exam form

Statement. A linear network delivers maximum power to a resistive load when RL = RTh. The maximum power is Pmax = VTh2/(4RTh). For an AC network with a complex load, the condition is ZL = ZTh*.

Derivation. PL = VTh2RL/(RTh+RL)2; set dPL/dRL = 0 ⇒ RL = RTh (step 2).

At the match. η = 50 %, VL = VTh/2, PL = Ps/2.

Traps

  • Using P = VTh2/(RTh + RL) (the crossed-out attempt on class p.13).
  • Saying "maximum power means maximum efficiency".
  • In the AC case, matching ZL = ZTh instead of the conjugate.
  • Forgetting to find RTh first when the source network is more than one resistor: use 06.

Self-test

  1. Derive RL = RTh (three lines).
  2. VTh = 12 V, RTh = 3 kΩ. Find Pmax and the source power at that point.
  3. Why do power companies not operate at maximum power transfer?
  4. ZTh = 50 − j20 Ω. Load for maximum power? If VTh = 10 V rms, what is Pmax?
  5. In the 06 board circuit (VTh = 20/3 V, RTh = 8/3 kΩ), what RL gets maximum power, and how much?

Answers

Check 1. (a) At the match, RTh = RL and both carry the same current, so I2RTh = I2RL: equal power in each, i.e. half of the total. (b) R = 5 kΩ; Pmax = 102/(4 × 5 kΩ) = 5 mW; η = 50 % (the source supplies 10 V × 1 mA = 10 mW).

Self-test.

  1. PL = VTh2RL/(RTh+RL)2; the numerator of the derivative is (RTh+RL)2 − 2RL(RTh+RL) = 0; this gives RTh2 = RL2, so RL = RTh.
  2. Pmax = 144/12k = 12 mW; I = 12/6k = 2 mA; Ps = 24 mW.
  3. Efficiency would be only 50 %: half of the generated power lost in the source and lines.
  4. ZL = 50 + j20 Ω; Pmax = 100/(4 × 50) = 0.5 W.
  5. RL = 8/3 kΩ ≈ 2.67 kΩ; Pmax = (20/3)2 / (4 × 8/3) = 4.17 mW.
