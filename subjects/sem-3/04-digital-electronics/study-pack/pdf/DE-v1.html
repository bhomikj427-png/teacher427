Unit 3 › Counters

B1 · Ripple (asynchronous) counters

Anna Univ. EC6302 · Apr/May 2015 · Part A Q6 · 2 marks What is the minimum no of flip flops needed to design a counter of modulus 60?
Guess first, on paper.

How it counts. Every FF has T = 1, so it toggles. FF0 toggles on each falling CLK edge. FF1 toggles whenever Q0 falls (1→0), and FF2 whenever Q1 falls. Reading Q2Q1Q0 gives 0, 1, 2 … 7, 0. That is an up counter. Clock the next stage from Q′ instead and it counts down. With positive-edge FFs the rule flips.

The flaw: ripple delay. Each stage waits for the one before it, so after edge 4 (011 → 100) the outputs pass through 010 and 000 before settling (shaded). The worst-case settle time is n·tpd. A decoder reading the outputs sees glitches, and fmax ≈ 1 / (n·tpd) drops as n grows. Synchronous counters fix this because every FF shares one clock.

Mod-N. n flip-flops give at most 2ⁿ states, so you need the smallest n with 2ⁿ ≥ N. To stop a ripple counter at N, detect the state N with a gate and use it to drive the asynchronous CLEAR. Mod-10: NAND(Q₃, Q₁) → CLR′ at 1010. Count 1010 appears for a few nanoseconds and is then cleared, which is another glitch.

Answer. 2⁵ = 32 < 60 ≤ 64 = 2⁶, so 6 flip-flops.
Check B1. (a) A 4-bit ripple counter uses FFs with tpd = 25 ns. Find the longest time it takes to settle after an edge. (b) Which gate inputs reset a mod-12 ripple counter?

Ring counter: feed Q3 back to D0. Preset it to 1000 and the single 1 circulates: 1000 → 0100 → 0010 → 0001. n FFs give mod-n. Each Q already marks one state, so no decoder is needed.

Unit 3 › Timing analysis

B4 · Timing analysis of sequential circuits

practice · no real paper item found · 4 marks A synchronous circuit has tpd,FF = 8 ns, tsu = 3 ns, th = 2 ns, and combinational delays of 12 ns on the longest path and 1 ns on the shortest. Find fmax and check the hold time.
Guess first, on paper.

Three numbers per flip-flop. tsu (setup): D must be stable before the edge. th (hold): D must stay stable after the edge. tpd: time from the edge until Q is valid. Break setup or hold and the FF can go metastable: its output sits between 0 and 1 for an unpredictable time.

Setup (longest path): data launched at edge n must reach FF2 a setup time before edge n+1, so Tclk ≥ tpd + tcomb,max + tsu, which gives fmax = 1 / (that sum).
Hold (shortest path): new data must not arrive while FF2 is still holding the old value, so tpd + tcomb,min ≥ th. The clock period is not in this inequality, so a slower clock cannot fix a hold violation.

Answer. Tmin = 8 + 12 + 3 = 23 ns, so fmax = 1/23 ns ≈ 43.5 MHz. Hold: 8 + 1 = 9 ns ≥ 2 ns, so hold is met.
Check B4. The same circuit gains 4 ns of extra logic on its longest path. Find the new fmax. Does the hold result change?

  6. K-map each FF input and each output, using unused codes as don't-cares.

Unit 4 › Timing issues

C4 · Timing issues in synchronous circuits

practice · no real paper item found · 4 marks A push-button signal enters a 100 MHz synchronous system directly. What can go wrong, and how is it fixed?
Guess first, on paper.
  • Clock skew. The clock reaches different FFs at different times. If skew works against the data direction it eats into the hold margin, and a slower clock cannot fix that. If it works with the data direction it eats into setup. Fix it with careful clock-tree layout.
  • Output glitches. Mealy outputs, or any decoded state, can glitch while the state bits change. If a glitch matters, register the output (use Moore style).
  • Asynchronous inputs → metastability. An input that is not timed to the clock will sometimes violate tsu/th. Fix: a 2-FF synchronizer (two D-FFs in series on the system clock). The second FF gives the first a full clock period to settle. This makes failure exponentially rarer but never impossible.
Answer. The button can change inside a setup/hold window, so the FF may go metastable and different FFs may read different values. Fix: debounce the switch (a monostable or an RC with a Schmitt trigger, C6), then pass it through a 2-FF synchronizer before any logic uses it.

C5 · Algorithmic State Machine (ASM) charts

Anna Univ. EC6302 · Apr/May 2015 · Q15(a)(i) · 8 marks Explain how a state graph for a sequential machine can be converted to an equivalent ASM chart.
Guess first, on paper: what in a flowchart could stand for "one clock"?

Three symbols.

  • State box (rectangle): one state, which lasts one clock. Moore outputs are written inside it.
  • Decision box (diamond): tests an input; 1 and 0 exits.
  • Conditional output box (oval): a Mealy output that is active only on that path.

An ASM block is one state box plus all the decisions and conditional outputs reachable from it in the same clock.

Conversion rule. Each state-graph node becomes a state box. Its outgoing arcs become a decision tree on the inputs. Each Moore output goes inside the state box. Each Mealy output (on an arc) becomes an oval on that branch.

Left: the Moore 010 detector from C2 as an ASM chart.

Answer outline (8 marks). The three symbols → definition of an ASM block → the four-step conversion rule → one converted example (the left figure). Advantage: it reads like an algorithm and maps directly onto the next-state and output logic.

C6 · Pulse trains, pseudo-random sequences, clock generation

practice · no real paper item found · 4 marks A 3-bit LFSR has feedback polynomial x³ + x + 1 (D₁ = Q₂ ⊕ Q₃) and starts at Q₁Q₂Q₃ = 100. List the states and find the period.
Guess first, on paper.

PRBS generator = LFSR. A shift register whose input is the XOR of chosen "tap" outputs. With a primitive polynomial it runs through all 2ⁿ − 1 non-zero states before repeating (a maximal-length or m-sequence). All-zeros is a lock-out: 0 ⊕ 0 = 0 forever, so the seed must be non-zero. The output looks random but repeats exactly, which makes it useful for test patterns, scramblers and spread spectrum.

Answer. 100 → 010 → 101 → 110 → 111 → 011 → 001 → 100. Period 7 = 2³ − 1, so this LFSR is maximal-length. The serial output (Q₃) is 0 0 1 0 1 1 1, repeating.

Pulse-train generator. Emits a fixed bit pattern, one bit per clock, over and over. Two easy builds: a recirculating shift register preloaded with the pattern (B2), or a mod-N counter followed by decode logic. The period equals the number of states.

Clock generation. Dividing an existing clock: a mod-N counter gives f/N, and k toggle FFs give f/2ᵏ. Making the clock in the first place is the job of a multivibrator:

TypeStable statesGives
Astable0free-running square wave, i.e. a clock
Monostable1one fixed-width pulse per trigger (debounce, timing)
Bistable2a latch / flip-flop

555 astable. C charges through R₁+R₂ up to ⅔VCC, then discharges through R₂ down to ⅓VCC. f = 1.44 / ((R₁ + 2R₂)C). Duty cycle = (R₁+R₂)/(R₁+2R₂), always > 50% in this circuit. Example: R₁ = 1 kΩ, R₂ = 10 kΩ, C = 10 nF gives f ≈ 6.86 kHz and duty ≈ 52%. 555 monostable: pulse width T = 1.1RC.

Ring oscillator. An odd number N of inverters in a loop has no stable state, so it oscillates at f = 1/(2N·tpd). Example: 5 inverters with 2 ns each give 50 MHz. It drifts with temperature and supply voltage. A crystal oscillator gives the precise system clock. A Schmitt trigger (two thresholds, with hysteresis) turns slow or noisy edges into clean ones.

Unit 4 › Asynchronous circuits

C7 · Asynchronous circuits: races and hazards

Anna Univ. EC6302 · Nov/Dec 2021 · Q15(b) · 13 marks What is the objective of state assignment in a asynchronous circuit? Give the hazard free realization for the Boolean function f (A, B, C, D) = ΠM (0, 2, 6, 7, 8, 10, 12).
Guess first, on paper: what goes wrong when two state bits must change "at once" with no clock?

Asynchronous = no clock. Outputs and state react directly to input changes, through feedback delays. Work in fundamental mode: change only one input at a time, and only after the circuit has settled. A stable state is one where next state = present state.

Races. If one transition needs two state variables to change, the delays decide which changes first. In a non-critical race every order ends in the same stable state. In a critical race the final state depends on the order, which is a bug. The objective of state assignment is to give codes that differ in only one bit to states that transition into each other, so critical races cannot happen.

Hazards. A static-1 hazard is a momentary 0 when F should stay at 1, because one product term turns off before the next one turns on. Static-0 is the dual, dynamic hazards bounce several times, and essential hazards are built into the flow table.

static-1 hazard: term 1 turns off before term 2 turns on, so F dips

The cure. On the K-map, every pair of adjacent 1s must sit inside one common group. Add the consensus (redundant) group for any adjacent pair that crosses between two groups.

Answer. ΠM(0,2,6,7,8,10,12) ⇒ the 1s are at Σm(1,3,4,5,9,11,13,14,15). Minimal cover: f = B′D + C′D + A′BC′ + ABC. Two adjacent pairs cross between groups: m11–m15 (B changes) and m13–m15 (C changes). One extra prime implicant, AD, covers both.
Hazard-free: f = B′D + C′D + A′BC′ + ABC + AD.
Check C7. F = AB + A′C. Which input change can glitch, and which term removes the glitch?

D1 · Noise margin, fan-out, delay, power

Anna Univ. EC6302 · Nov/Dec 2021 · Part A Q2 · 2 marks Define Noise margin.
RTU (3E2075, 2012) Digital Electronics · Unit II Q(a) · 8 marks Define the (i) noise immunity and (ii) Fanout.
Guess first, on paper. Then: why must "1" be a range of voltages?

Noise margin is how much noise voltage a signal can pick up between one gate's output and the next gate's input and still be read correctly: NMH = VOH(min) − VIH(min), NML = VIL(max) − VOL(max). The guaranteed output is always better than what the input needs, and that gap is the margin.

Fan-out is the number of gate inputs one output can drive while staying in spec. It is limited by current in both states: fan-out = min(IOL/IIL, IOH/IIH). Fan-in is the number of inputs a gate has.

Standard TTL (74xx), VCC = 5 V
VOH(min) 2.4 VVOL(max) 0.4 VVIH(min) 2.0 VVIL(max) 0.8 V
IOH 400 µAIOL 16 mAIIH 40 µAIIL 1.6 mA

⇒ NMH = NML = 0.4 V; fan-out = min(16/1.6, 400/40) = 10. tpd ≈ 10 ns, P ≈ 10 mW, so the power–delay product ≈ 100 pJ. That figure of merit is the energy per switching event.

Answer. Noise margin (noise immunity): the largest noise voltage that can be added to a valid logic level without changing how it is read. Give both formulas above. Fan-out: the maximum number of standard loads one output can drive without its levels leaving spec. It is set by the current ratios.

Unit 5 › TTL

D2 · The TTL NAND gate (totem pole)

practice · textbook-style (Jain, TTL chapter) · 8 marks Draw the circuit of a standard TTL NAND gate with totem-pole output and explain its operation. Why can't two totem-pole outputs be tied together?
Guess first, on paper.
Standard 7400 TTL NAND, totem-pole output · Wikimedia Commons, CC BY 2.0 de. German labels: V₁…V₄ = transistors Q1…Q4, V₅ = diode D, U = voltage.
  • Q1 (multi-emitter) does the AND. Each emitter is one input.
  • Any input LOW → Q1's base current flows out through that emitter → Q2 OFF → Q4 OFF, and Q3 gets base current through R₂ → Q3 + D pull the output HIGH.
  • All inputs HIGH → Q1's base–collector junction drives Q2 ON → Q4 saturates, output LOW. Q2's collector drops, and the diode D makes sure Q3 stays OFF.
  • Totem pole (Q3 on top of Q4): there is an active transistor both pulling up and pulling down, so output impedance is low in both states and edges are fast.
  • Never tie two outputs together. If one drives HIGH while the other drives LOW, Q3 of one gate shorts to Q4 of the other through only 130 Ω, and a large current flows. For shared lines use open-collector (external pull-up, gives wired-AND) or tristate.
  • An unconnected TTL input acts as a HIGH (no emitter current flows), but it picks up noise. Tie unused inputs to a defined level.

Sub-families trade speed against power: 74 (standard), 74L (low power), 74H (high speed), 74S (Schottky: a clamp stops saturation, so it is faster), 74LS (low-power Schottky, the workhorse), 74AS/ALS/F.

Unit 5 › Tristate

D3 · Tristate TTL

Anna Univ. EC6302 · Nov/Dec 2021 · Q11(b)(i) · 8 marks Draw and explain Tri-state TTL inverter circuit diagram with its operation.
Anna Univ. EC1201 · Nov/Dec 2021 · Part A Q3 · 2 marks What is tristate logic? What are the demerits?
Guess first, on paper: how can one output be "neither 0 nor 1"?

Third state = high impedance (Hi-Z). When the enable input is inactive, the output is electrically disconnected. This lets many outputs share one bus, with only the enabled one driving it.

Circuit. Start from the totem-pole gate above and add an enable input E. It connects (1) to an extra emitter of Q1 and (2) through a diode to Q2's collector (Q3's base). When disabled (E LOW), the extra emitter steals Q1's base current, so Q2 and Q4 are OFF, and the diode pulls Q3's base LOW, so Q3 is OFF too. Both totem-pole transistors are OFF, so the output is Hi-Z. When enabled (E HIGH), the diode is reverse-biased and the gate works normally.

Answer. Tristate logic has outputs 0, 1 and Hi-Z, selected by the enable. Merit: it keeps the fast active pull-up (unlike open-collector) and still allows bus sharing. Demerits: if two enables are on at once, two outputs fight (bus contention, large current), so control logic must arbitrate. A bus with every output in Hi-Z floats, so it needs pull-ups or bus-keepers. Enable/disable times add delay.
Unit 5 › ECL

D4 · Emitter-coupled logic

RTU (3E2075) · Unit II Q(b) · 8 marks Explain the parameters used to characterize logic families. Calculate the noise margin of ECL gate.
Anna Univ. EC1201 · Nov/Dec 2021 · Q12(b)(i) · 10 marks Compare the features of TTL, ECL and HTL families.
Guess first, on paper: what makes a bipolar transistor slow to turn OFF?

A current switch. RE sets a nearly constant current. Whichever transistor, Q1 (input A) or Q2 (fixed reference VBB), has the higher base takes that current. The current is steered, never switched off, and neither transistor saturates.

Why it is the fastest family (about 1 ns). A saturated BJT stores extra charge that must be removed before it can turn off. ECL never saturates, so it never pays that delay.

Costs. Highest power (the current always flows). Small voltage swing (logic 1 ≈ −0.8 V, logic 0 ≈ −1.7 V, about 0.8 V apart), so the noise margin is small. It runs from a negative supply (VEE = −5.2 V, VCC = 0). It gives both OR and NOR outputs.

Noise margin, method. Same formulas as D1, applied to ECL levels. With typical 10K-series values VOH(min) = −0.98 V, VIH(min) = −1.105 V, VIL(max) = −1.475 V, VOL(max) = −1.63 V: NMH = −0.98 − (−1.105) = 0.125 V, NML = −1.475 − (−1.63) = 0.155 V. These levels are illustrative. Datasheet values vary with series and temperature; use the levels the paper gives you.

D5 · CMOS gates and interfacing

Anna Univ. EC1201 · Nov/Dec 2021 · Q12(a)(i) · 10 marks Draw a CMOS NAND gate and explain its operation. List the characteristics of CMOS Logic family.
RTU (3E2075) · Unit II OR-Q(a) · 8 marks What are the different schemes for CMOS to TTL interface. Explain one of them.
Guess first, on paper: when is there no path from VDD to ground?

CMOS NAND · Wikimedia Commons, CC BY-SA 3.0

Rule. Each gate has a PMOS pull-up network and an NMOS pull-down network that are logical complements, so exactly one of them conducts. NAND: NMOS in series (both inputs must be 1 to pull the output LOW) and PMOS in parallel (any 0 pulls it HIGH). NOR is the reverse.

A BNMOS (series)PMOS (parallel)Out
0 0both offboth on1
0 1 / 1 0one off → openone on1
1 1both onboth off0

Characteristics. Static power ≈ 0, because in steady state no path conducts. Dynamic power P = αCVDD²f, so power rises with frequency. Output swings rail to rail. Noise margin is large. Fan-out is very high (the input is a gate capacitor). Supply range is wide, density is high, and it scales well, which is why CMOS took over. Weak points: it is sensitive to static (ESD), and it is slower with large capacitive loads.

Handling (EC1201 Q12(b)(ii), 6 marks). Store parts in conductive foam. Ground yourself and the bench. Never insert or remove a part with power on. Tie every unused input to VDD or GND, because a floating CMOS input wanders and can turn both networks partly on.

Interfacing: always compare levels and currents.

  • TTL → CMOS (5 V): TTL's VOH(min) = 2.4 V is below a 74HC input's VIH ≈ 3.5 V. Fix: a pull-up resistor to +5 V, or use 74HCT (CMOS with TTL input thresholds).
  • CMOS → TTL: the voltage levels are fine, but a CMOS output must sink TTL's IIL = 1.6 mA per load. 74HC can sink this for a few loads. 4000-series cannot, so add a buffer (e.g. 4049/4050) or drive LS-TTL (lower IIL). With different supply voltages, use a level-shifter.

Anna Univ. EC6302 · Apr/May 2015 · Q14(a)(i) · 8 marks Explain memory decoding. Compare the RAM, ROM, PROM & EPROM.
Guess first, on paper: which cell needs refreshing, and why?

Organisation. 2ᵏ words × m bits: k address lines, m data lines. The row decoder raises one word line, and that row's cells connect to the bit lines. Example: 1K × 8 → 2¹⁰ words → 10 address lines, 8 data lines, 8192 bits.

Memory decoding (building a big memory from small chips). For 4K × 8 from four 1K × 8 chips: A₉–A₀ go to every chip, and A₁₁A₁₀ go to a 2:4 decoder whose outputs drive each chip's chip-select. Each chip then occupies its own 1K block of addresses.

Working. SRAM: the word line turns on M5/M6, the latch drives BL and BL′, and a sense amplifier reads the difference. To write, force BL/BL′ hard enough to flip the latch. Implementing on a PLA: minimise every output as SOP, look for products shared between outputs, then mark the connections. Example: F₁ = Σm(4,5,7) = AB′ + AC, F₂ = Σm(3,5,7) = BC + AC. That needs 3 product terms, not 4, because AC is shared.

This is the PLA programming table that exam answers ask for: 1 = true input, 0 = complemented input, – = not connected. Beyond these: GAL (a re-programmable PAL), CPLD (many PALs on one chip), and FPGA (look-up tables, essentially small MUX-based ROMs, programmed in Verilog).

Answers. PLA: a PLD with programmable AND and OR arrays, so it generates only the product terms needed, and outputs can share them. A ROM has a fixed AND array that generates all 2ⁿ minterms. PAL vs PLA: PAL's OR array is fixed, which makes it faster and cheaper but less flexible, with no sharing between outputs. PLA programs both arrays.
