Part D · Unit 4

State machines

A counter (C8) is a circuit that walks through a fixed list of states. Add an input that decides which state comes next and an output, and you have a finite state machine (FSM): the general form of every synchronous circuit. The design steps are the six steps of C8 with two more in front: turning words into a state diagram, and removing states that are not needed.

Equivalent states: two states are equivalent if, for every input, they give the same output and go to equivalent next states. No input sequence can tell them apart, so they can be merged into one. Fewer states can mean fewer flip-flops and simpler logic.

Method 1: partitioning. Keep splitting the set of states until nothing splits.

  • P₀ = (ABCDE).
  • P₁, split by outputs: A, B, C give (1, 0); D, E give (0, 1). → (ABC)(DE).
  • P₂, split by the block each next state falls in. On x = 1: A → B, which is in block (ABC), but B → E and C → E, in block (DE). So A separates: (A)(BC). On x = 1: D → B but E → A; they were in one block in P₁, so (DE) stays for now. → (A)(BC)(DE).
  • P₃: on x = 1, D → B, in block (BC), but E → A, in block (A). D and E separate. → (A)(BC)(D)(E).
  • P₄ = P₃: B and C go to C, B (same block) and E, E. Stop.
{{ implication_chart() }}

Method 2: implication table. One cell for each pair of states.

  1. Cross out (×) every pair whose outputs differ.
  2. In each remaining cell write the pairs of next states that would have to be equivalent.
  3. Cross out any cell that depends on a crossed-out pair. Repeat until nothing changes.
  4. The cells left uncrossed are the equivalent pairs.

Here A–B needs B–E, which is crossed out, so A–B goes. D–E needs A–B, so it goes too. B–C needs only C–B (itself) and E–E, so it survives.

Incompletely specified machines (deck 12 slides 19–26). When some next states or outputs are don't-cares, equivalence is replaced by compatibility: two states are compatible if their specified outputs never conflict and their next states are compatible. Compatibility is not transitive (A–B and B–C compatible does not make A–C compatible), so states are grouped into maximal compatibles with a merger diagram (states as dots, a line joining each compatible pair; a fully connected group is a compatible). The reduced machine uses a set of compatibles that covers every state and is closed: the next states of each chosen group fall inside one chosen group.

D4 · Algorithmic state machine (ASM) charts

Practice · deck 13 slides 3–8 (the deck draws the chart for a 1010 detector) Name the three elements of an ASM chart and draw the ASM chart of the Mealy 1101 detector of D2.
Guess first: in a flowchart of the machine, which shape should take exactly one clock period?
{{ asm_1101() }}
ASM chart: a flowchart that describes a state machine. Unlike an ordinary flowchart it carries timing: each state box lasts one clock period.

Three elements.

  • State box (rectangle): one state. Its name is written beside or inside it, and any Moore output is listed inside. One entry, one exit.
  • Decision box (diamond): tests an input and has an exit for 0 and an exit for 1.
  • Conditional output box (oval): an output that is produced only on that path. It always follows a decision box. This is a Mealy output.

ASM block: one state box together with the decision and conditional boxes reached from it before the next state box. Everything in one block happens in the same clock period.

From state diagram to ASM chart. Each circle becomes a state box. Its outgoing arrows become a decision box on the input. An output written inside a circle (Moore) goes inside the state box; an output written on an arrow (Mealy) becomes an oval on that exit.

From ASM chart to circuit. Read off the state table (each path from one state box to the next is one row), then continue with the D2 steps.

The deck's other charts: MOD-6 counter, D and JK flip-flops, serial adder (two states: carry 0 and carry 1), 2-bit up and up/down counters.

Answer. State box, decision box, conditional output box. Chart on the left: four state boxes A–D, one decision on x after each, and a single oval (z = 1) on the x = 1 exit of D, the only place where the Mealy output is 1.

Unit 4 › Timing issues

D5 · Timing issues in synchronous circuits

Practice A push-button signal is connected straight into a 100 MHz synchronous system. What can go wrong, and how is it fixed?
Guess first: the button is pressed at a random moment. What does C9 say about a D input that changes right at a clock edge?
  • Clock skew. The clock reaches different flip-flops at slightly different times. If the receiving flip-flop gets its clock late, the new data may arrive before it has finished holding the old value: skew eats into the hold margin, and a slower clock cannot fix that. Skew the other way eats into the setup margin. Fix: route the clock carefully so every flip-flop gets it together.
  • Output glitches. A Mealy output, or any output decoded from several state bits, can show a short false pulse while the inputs or state bits are changing. If that matters, take the output from a flip-flop (Moore style).
  • Asynchronous inputs and metastability. An input that is not timed by the clock will sometimes change inside a setup/hold window (C9). The flip-flop may then hang between 0 and 1. Fix: a synchronizer, two D flip-flops in series on the system clock. The second flip-flop gives the first a whole clock period to settle. Failure becomes extremely rare, though never impossible.
Answer. The button can change inside a setup/hold window, so a flip-flop can go metastable and different flip-flops can read different values. A mechanical button also bounces: it makes several pulses per press. Fix: debounce the switch (an SR latch across a two-way switch, or an RC filter with a Schmitt trigger), then pass it through a two-flip-flop synchronizer before any logic uses it.

D6 · Pulse-train generator, pseudo-random sequence generator, clock generation

Practice A 3-bit shift register has its input fed by D1 = Q2 ⊕ Q3 and starts at Q1Q2Q3 = 100. List its states and find the length of the sequence.
Guess first: 3 flip-flops have 8 states. Can this circuit ever reach 000 from 100? What happens if it starts at 000?
{{ chain(3, "lfsr") }}

Pseudo-random binary sequence (PRBS) generator. A shift register whose input is the XOR of chosen outputs ("taps"); it is called a linear-feedback shift register (LFSR). With the right taps it passes through all 2ⁿ − 1 non-zero states before repeating (a maximal-length sequence). The state 000 is a lock-out: 0 ⊕ 0 = 0 for ever, so it must never start there. The output looks random but repeats exactly. Uses: test patterns, scrambling data, spread-spectrum codes.

Answer. 100 → 010 → 101 → 110 → 111 → 011 → 001 → 100. Seven states = 2³ − 1, the maximal length. The output at Q3 is 0 0 1 0 1 1 1, repeating.

Pulse-train generator. A circuit that puts out a fixed bit pattern again and again, one bit per clock. Two ways to build it: (1) a shift register connected as a ring and loaded with the pattern (C6); (2) a MOD-N counter followed by logic that gives the wanted bit for each count (the counter's state table with one extra output column, minimised by K-map). The pattern length is the number of states.

Clock generation. To get a slower clock from an existing one, divide it: a MOD-N counter gives f/N, and k toggle flip-flops give f/2ᵏ (C7). To make a clock in the first place needs an oscillator:

{{ astable_555() }}

555 timer as an astable. The capacitor charges through R₁ + R₂ up to ⅔VCC, then discharges through R₂ down to ⅓VCC, and repeats. f = 1.44/((R₁ + 2R₂)C); duty cycle = (R₁ + R₂)/(R₁ + 2R₂). Example: R₁ = 1 kΩ, R₂ = 10 kΩ, C = 10 nF gives f = 6.86 kHz, duty 52%. As a monostable, the pulse width is 1.1RC.

{{ ring_osc() }}

Ring oscillator. An odd number N of inverters in a loop has no stable state and oscillates at f = 1/(2N·tpd). Five inverters of 2 ns each give 50 MHz. Its frequency drifts with temperature and supply voltage, so a system clock uses a crystal oscillator instead.

D7 · Asynchronous circuits: races and hazards

Practice · Anna University EC6302, Nov/Dec 2021, Q15(b), 13 marks What is the objective of state assignment in a asynchronous circuit? Give the hazard free realization for the Boolean function f(A, B, C, D) = ΠM(0, 2, 6, 7, 8, 10, 12).
Guess first: with no clock, two state bits are told to change "at the same time". What decides which one changes first?
Asynchronous sequential circuit: one with no clock. Its state is held in feedback loops, and it reacts as soon as an input changes. · Stable state: next state = present state, so nothing further changes. · Fundamental mode: the operating rule: change only one input at a time, and only after the circuit has settled.

Design outline. Word description → primitive flow table (one stable state per row) → merge rows → state assignment → excitation equations → circuit. A flow table is a state table with the stable states circled.

Races. If one transition needs two state variables to change, they cannot change at exactly the same instant; gate delays decide the order. In a non-critical race every order ends in the same stable state. In a critical race the final state depends on the order: the circuit is wrong some of the time.

Hazards. A hazard is a momentary wrong output caused by unequal gate delays. Static-1 hazard: the output should stay 1 but dips to 0, because one product term switches off before the next one switches on. Static-0 is the opposite; a dynamic hazard is an output that should change once but bounces. In an asynchronous circuit such a pulse can be taken as a real input change, so hazards must be designed out.

static-1 hazard: term 1 turns off before term 2 turns on, so F dips

The cure. On the K-map, every pair of adjacent 1s must lie inside one common group. Wherever two neighbouring 1s are in different groups only, add a group that covers both (it is a redundant, consensus term).

Answer. Objective of state assignment: give codes that differ in only one bit to states that have a transition between them, so that only one state variable changes at a time and no critical race can occur.
Hazard-free realization: ΠM(0, 2, 6, 7, 8, 10, 12) means the 1s are Σm(1, 3, 4, 5, 9, 11, 13, 14, 15). Minimal cover: f = B'D + C'D + A'BC' + ABC. Two adjacent pairs are not inside a common group: cells 11 and 15, and cells 13 and 15. One more group, AD (cells 9, 11, 13, 15), covers both.

f = B'D + C'D + A'BC' + ABC + AD

Table (next state for x = 0, x = 1; output): S0 → S0, S1; 0 · S1 → S2, S1; 0 · S2 → S0, S3; 0 · S3 → S2, S4; 0 · S4 → S2, S1; 1. From S4 a 1 goes to S1 and a 0 goes to S2, because the final "1" of 1011 can start a new pattern. (b) The arrow D —1/1→ B becomes D —1/1→ A: after a match the machine starts from nothing. (c) Mealy 3 (nothing, "1", "11"); Moore 4 (one more state to hold the output).
  2. D3. P₁ by outputs: (AD)(BE)(CF)(GH). P₂: on x = 1, G → G but H → B, which are in different blocks, so G and H separate. A and D go to E, B (same block) and D, A (same block); B and E go to A, D and F, C; C and F go to C, C and A, D. → (AD)(BE)(CF)(G)(H). P₃ = P₂. 8 states become 5: A ≡ D, B ≡ E, C ≡ F.
  3. D4. (a) Inside the state box of E, because a Moore output belongs to the state. (b) Six, one per count. (c) A conditional output depends on an input, so an input must be tested first, and that is a decision box.
  4. D5. (a) Setup: a longer period gives the data more time to arrive. Hold does not involve the period. (b) A Moore output depends only on flip-flop outputs, which change once per clock edge. A Mealy output also depends directly on the input, which can change at any time.
