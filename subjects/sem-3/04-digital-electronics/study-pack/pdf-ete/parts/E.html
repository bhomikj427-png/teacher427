Part E · Unit 5

Logic families, memories and programmable devices

Parts A–D treated a gate as an ideal box. A real gate is a transistor circuit with real voltages, currents and delays. A logic family is a set of chips built with the same basic gate circuit, so they share those numbers. This part gives the yardsticks for comparing families, the three families in the syllabus (TTL, ECL, CMOS), and then two ways of buying logic in bulk: memories and programmable logic devices.

E1 · The yardsticks: noise margin, fan-out, delay, power

Practice · deck 14 slides 4–12 Define noise margin and fan-out. For standard TTL (VOH(min) = 2.4 V, VOL(max) = 0.4 V, VIH(min) = 2.0 V, VIL(max) = 0.8 V; IOH = 400 μA, IOL = 16 mA, IIH = 40 μA, IIL = 1.6 mA) calculate both.
Guess first: a gate promises its HIGH output is at least 2.4 V, and accepts anything above 2.0 V as HIGH. Why the gap?
VOH(min), VOL(max): the worst HIGH and LOW voltages a gate output is guaranteed to give. · VIH(min), VIL(max): the lowest voltage an input is guaranteed to read as HIGH, and the highest it reads as LOW. · IOH, IOL: the current an output can supply when HIGH and sink when LOW. · IIH, IIL: the current one input takes in each state.
{{ noise_bands() }}

Noise margin (noise immunity): the largest noise voltage that can be added to a signal between one gate's output and the next gate's input without changing how it is read.

NMH = VOH(min) − VIH(min)     NML = VIL(max) − VOL(max)

{{ fanout_fig() }}

Fan-out: the number of gate inputs that one output can drive and still keep its levels. It is limited by current in both states: fan-out = the smaller of IOL/IIL and IOH/IIH. Fan-in: the number of inputs a gate has.

YardstickDefinition
Propagation delay tpTime from an input change to the output change, measured between the 50% points. tPHL (output going HIGH → LOW) and tPLH differ; tp is their average. Smaller = faster.
Rise time, fall timeTime for the output to go from 10% to 90% of its swing, and from 90% to 10%.
Power dissipationSupply voltage × average supply current. Static: with no switching. Dynamic: extra power used at each transition, so it grows with frequency.
Speed–power producttp × power per gate, in joules: the energy per switching event. A figure of merit; smaller is better.
Integration levelGates per chip: SSI under 12, MSI 12–99, LSI 100–9999, VLSI 10 000 and above.
Answer. Definitions above. NMH = 2.4 − 2.0 = 0.4 V; NML = 0.8 − 0.4 = 0.4 V. Fan-out: LOW state 16 mA/1.6 mA = 10; HIGH state 400 μA/40 μA = 10; so fan-out = 10. With tp ≈ 10 ns and 10 mW per gate, the speed–power product is 100 pJ.

Unit 5 › TTL

E2 · The TTL NAND gate

Practice · deck 14 slides 24–25 (syllabus item "TTL NAND gate") Draw the circuit of a standard TTL NAND gate with totem-pole output and explain its operation. Why must two totem-pole outputs not be connected together?
Guess first: the output stage has one transistor to pull the output up and one to pull it down. What happens if both conduct at once?
TTL (transistor–transistor logic): the family built from bipolar transistors (BJTs), supply +5 V. A BJT used as a switch is either OFF (no current) or saturated (fully ON).
{{ ttl_nand() }}
  • Q1, the input transistor with one emitter per input, does the AND.
  • Any input LOW: Q1's base current flows out through that emitter, so Q2 gets no base current and is OFF. Then Q4 is OFF, and Q3 gets base current through its resistor, turns ON, and pulls the output HIGH through the diode.
  • All inputs HIGH: Q1's base current now flows through its collector into Q2. Q2 turns ON and drives Q4 into saturation: the output is LOW. Q2's collector is now low, and the diode makes sure Q3 stays OFF.
  • Totem-pole output (Q3 stacked on Q4): one transistor actively pulls up and one actively pulls down, so the output resistance is low in both states and switching is fast.

Other facts. An unconnected TTL input behaves as HIGH (no emitter current flows) but picks up noise, so tie unused inputs to a fixed level. Sub-families trade speed against power: 74 (standard), 74L (low power), 74H (high speed), 74S (Schottky: a clamp diode stops the transistors saturating, so they switch off faster), 74LS (low-power Schottky, the common one), 74AS, 74ALS.

Answer. Circuit and operation above: output = (A·B)'. If two totem-pole outputs are joined and one tries to go HIGH while the other is LOW, Q3 of one gate and Q4 of the other form a path from +5 V to ground through a very small resistance. A large current flows and can damage the gates, and the output voltage is not a valid level. Lines shared by several outputs use open-collector outputs (no Q3; an external pull-up resistor; outputs joined together give a wired-AND) or tristate outputs (E3).

E3 · Tristate TTL

Practice · deck 05 slides 44–48 (tri-state devices) What is tristate logic? Explain how the third state is obtained in a TTL gate, and give one use.
Guess first: how can an output be neither 0 nor 1?
{{ tristate_bus() }}

The third state is high impedance (Hi-Z). When the enable input is inactive the output is electrically disconnected: it neither pulls up nor pulls down. Many outputs can then share one wire (a bus), as long as only one is enabled at a time.

Circuit. Start from the totem-pole gate of E2 and add an enable input. When the gate is disabled, the enable line (1) pulls an extra emitter of Q1 LOW, which turns Q2 and Q4 OFF, and (2) through a diode pulls the base of Q3 LOW, which turns Q3 OFF. Both output transistors are OFF, so the output floats. When enabled, the diode is reverse biased and the gate works normally.

Answer. Logic with three output states: 0, 1 and high impedance. It is obtained by turning both totem-pole transistors off. Use: several devices sharing a data bus. Compared with open-collector it keeps the fast active pull-up. Drawback: if two enables are active together the outputs fight (bus contention), so the enables must be decoded so that only one is active.

Unit 5 › ECL

E4 · Emitter-coupled logic (ECL) and the family comparison

Practice (syllabus item "ECL"; comparison table as in deck 14 slide 14) Why is ECL the fastest logic family? Compare TTL, ECL and CMOS.
Guess first: a saturated transistor has extra charge stored in it. What must happen to that charge before it can switch off?
{{ ecl_gate() }}

A current switch. RE sets an almost constant current. It flows through whichever transistor has the higher base voltage: Q1 (the input) or Q2 (held at a fixed reference VBB). The current is steered from one side to the other, never switched off, and neither transistor ever saturates.

Why it is fast (about 1 ns). A saturated transistor must first get rid of stored charge before it turns off (storage delay). ECL transistors never saturate, and the voltage swing is small, so there is little to charge and discharge.

Costs. The current always flows, so power is the highest of any family. The swing is small (logic 1 ≈ −0.8 V, logic 0 ≈ −1.7 V), so the noise margin is small. It uses a negative supply (VEE = −5.2 V). Each gate gives both OR and NOR outputs.

E5 · CMOS gates and interfacing

Practice · deck 14 slides 19–22 Draw a CMOS inverter and a 2-input CMOS NAND gate and explain their operation. Why does CMOS use almost no static power?
Guess first: in the inverter below, is there any input value for which both transistors are ON?
nMOS transistor: a switch that is ON when its gate is HIGH; it connects the output to ground. · pMOS transistor: ON when its gate is LOW; it connects the output to VDD. · CMOS (complementary MOS): every gate uses both kinds, arranged so that one network is ON exactly when the other is OFF.
{{ commons("CMOS_Inverter.svg", 170) }}
CMOS inverter · Wikimedia Commons, public domain
{{ commons("CMOS_NAND.svg", 190) }}
CMOS NAND · Wikimedia Commons, CC BY-SA 3.0

Inverter. Input LOW: the pMOS is ON, the nMOS is OFF, the output is pulled to VDD. Input HIGH: the nMOS is ON, the pMOS is OFF, the output is pulled to ground.

NAND. Two nMOS in series to ground: the output is LOW only if both inputs are 1. Two pMOS in parallel to VDD: either input at 0 pulls the output HIGH. A NOR gate is the reverse: nMOS in parallel, pMOS in series. An n-input gate uses 2n transistors.

Characteristics. Static power almost zero. Dynamic power P = C·VDD²·f: each transition charges or discharges the load capacitance C, so power rises with frequency. Output swings the full range 0 to VDD, so the noise margin is large. The input is a capacitor that takes almost no current, so fan-out is very high. Wide supply range, small transistors, high packing density. Weak points: the thin gate oxide is damaged by static electricity, and speed falls with large capacitive loads. Handling: store in conductive foam, ground yourself, and never leave an input unconnected: a floating input drifts and can turn both networks partly ON.

Interfacing: check voltage levels and currents in both states.

Answer. Circuits and operation above. In either steady state one of the two networks is OFF, so there is no path from VDD to ground and no current flows. Power is used only while switching.

E6 · Semiconductor memories

Practice (syllabus item "memory elements"; the decks have no memory slides) Differentiate static and dynamic RAM. A memory is specified as 1K × 8: how many address lines and data lines does it have? How is a 4K × 8 memory built from 1K × 8 chips?
Guess first: to pick one of 1024 words, how many bits must the address have?
Memory cell: stores one bit. · Word: a group of bits read or written together. · Address: the number that selects one word. · RAM: read-and-write memory; loses its contents without power (volatile). · ROM: read-only memory; keeps its contents without power.
{{ memory_org() }}

Organisation. A memory of 2ᵏ words × m bits has k address lines and m data lines. A decoder (B2) turns the address into one active word line; the cells of that word connect to the bit lines. Control inputs: chip select (CS) and read/write.

E7 · Programmable logic devices

Professor's deck 15 · slides 31–34 Implement the following two Boolean functions with a PLA: F1(A, B, C) = Σ(0, 1, 2, 4), F2(A, B, C) = Σ(0, 5, 6, 7).
Guess first: every SOP is a layer of ANDs feeding a layer of ORs. Which layer would you make programmable?
PLD: one chip containing an array of AND gates feeding an array of OR gates, with connections the user can program, so it replaces many fixed-function chips. · Product term: the output of one AND gate. In PLD diagrams a gate's many inputs are drawn as one line, and × marks a programmed connection.
{{ pld_arrays() }}
AND arrayOR arrayNotes
PROMfixed: a decoder that makes all 2ⁿ mintermsprogrammableStores the truth table directly; no minimisation needed. Size doubles with every extra input.
PALprogrammablefixedEach output has its own fixed number of product terms, which cannot be shared. Faster and cheaper than a PLA.
PLAprogrammableprogrammableMost flexible: product terms can be shared between outputs. An XOR on each output can invert it.

PROM (deck 15 slides 19–22): an 8 × 4 ROM has 3 address inputs and 4 outputs. Each output is the OR of the minterms marked for it. For a function given as Σm, mark exactly those minterms.

PLA design. A PLA has a limited number of AND gates, so the aim is the fewest distinct product terms. Minimise each function and its complement, and choose the forms that share the most terms; the output XOR supplies the complement when needed.

Answer. F1 directly is A'B' + A'C' + B'C', three terms shared with nothing. Its complement (group the 0s: cells 3, 5, 6, 7) is F1' = AB + AC + BC. F2 = AB + AC + A'B'C'. Two terms are common, so use F1 = (AB + AC + BC)' with the output inverted: 4 product terms instead of 6.

This PLA programming table is the answer the exam wants: 1 = variable connected, 0 = its complement connected, – = not connected.

PAL design (deck 15 slides 25–27). Each output section has a fixed number of AND gates, say three. For w = ABC' + A'B'CD', x = A + BCD, y = A'B + CD + B'D', z = ABC' + A'B'CD' + AC'D' + A'B'C'D: z needs four terms, but its first two are w. Feed w back as an input and write z = w + AC'D' + A'B'C'D, which fits in three.

Larger devices. SPLD (simple PLD): PROM, PAL, PLA, GAL (an erasable PAL), about 200 gates. CPLD: several PAL-like blocks on one chip joined by programmable wiring. FPGA: thousands of small look-up tables (tiny memories that hold truth tables) with programmable wiring, the largest capacity. All are described in a hardware description language (Verilog or VHDL).
