No Digital Electronics end-term paper or blueprint has been seen, so the real format is unknown. This paper copies the layout of the one official blueprint in hand for this session (MAS2001, July–Nov 2026): Part A 10 × 2 marks, Part B 6 × 6 marks, Part C 2 × 8 marks, Part D 1 × 8 marks, total 80. Questions with a source tag are the professor's own and were not used earlier in this pack.

Part A · 10 × 2 = 20 marks

  1. State De Morgan's two theorems.
  2. Convert F(A, B, C) = Σm(1, 3, 6) to product-of-maxterms form.
  3. Why is the NAND gate called a universal gate?
  4. How many select lines does a 16:1 multiplexer have? How many 4:1 multiplexers build it as a tree?
  5. Find the odd parity bit for the data word 1101001.
  6. Give two differences between a latch and a flip-flop.
  7. How many flip-flops does a MOD-12 counter need, and how many states are left unused?
  8. Give two differences between a Mealy machine and a Moore machine.
  9. A gate has VOH(min) = 2.7 V, VIH(min) = 2.0 V, VIL(max) = 0.8 V, VOL(max) = 0.5 V. Find its noise margins.
  10. Differentiate PAL and PLA.

Part B · 6 × 6 = 36 marks

  1. Design a combinational circuit having 4 inputs that will produce an output '1' when two consecutive input bits are 1 and produce '0' for other cases. practice set 1, Q4
  2. Implement the following Boolean function using 8:1 multiplexer: F(P, Q, R, S) = Σm(0, 2, 5, 9, 11, 12, 14, 15). practice set 1, Q6
  3. Implement the following function using suitable decoder: F(a, b, c, d) = Σm(0, 1, 2, 5, 6, 8, 9, 15). practice set 1, Q8
  4. Design 2-bit synchronous up counter. practice set 2, Q4 Use JK flip-flops and show the state table, the excitation table and the circuit equations.
  5. Reduce the following state table by partitioning and give the equivalent states. deck 12, slide 18
    PresentABCDEFGH
    Next/z, x = 0D/0C/1C/1D/0C/1D/0G/0B/1

  6. Draw the circuit of a two-input TTL NAND gate with totem-pole output and explain its operation. A TTL family has IOL = 8 mA, IIL = 0.4 mA, IOH = 0.4 mA, IIH = 20 μA: find its fan-out.

Part C · 2 × 8 = 16 marks

  1. Design a Moore circuit to detect a sequence: if the input x = 1011 then output z = 1, otherwise z = 0. deck 11, slide 43, Q1 Allow overlap, use D flip-flops, and give the state diagram, state table and flip-flop input equations.
  2. Realize the following functions using PAL: F1(A, B, C, D) = Σm(1, 4–7, 10–13), F2 = Σm(4–7, 10–11), F3 = Σm(4–7, 9–15). deck 15, slide 28; all three taken as functions of A, B, C, D The PAL has three product terms per output. Give the minimal expressions and the PAL programming table.

Part D · 1 × 8 = 8 marks

  1. (a) Design a MOD-6 synchronous up counter (0 to 5) using JK flip-flops, and check whether it is self-starting. (b) An asynchronous MOD-6 counter is wanted instead. State how many flip-flops it needs, which outputs feed the reset gate, and one disadvantage compared with the synchronous design.

Key: mock paper

  1. (X + Y)' = X'·Y' and (X·Y)' = X' + Y'. The complement of a sum is the product of the complements, and the reverse. (A1)
  2. ΠM lists the rows left out: F = ΠM(0, 2, 4, 5, 7). (A2)
  3. NOT, AND and OR can each be built from NAND gates alone, so any logic function can. (A5)
  4. 4 select lines (2⁴ = 16). Five 4:1 MUXes: four in the first level and one to choose among them. (B1)
  5. 1101001 has four 1s (even), so the odd parity bit is 1. (B6)
  6. A latch is level-triggered and is transparent while its enable is active; a flip-flop is edge-triggered and changes only at a clock edge. A latch needs no clock and can pass input glitches; a flip-flop samples its input once per clock cycle. (C1, C2)
  7. 2³ = 8 < 12 ≤ 16, so 4 flip-flops; 16 − 12 = 4 unused states. (C7)
  8. Mealy: output depends on state and input, written on the arrows, changes as soon as the input changes, fewer states. Moore: output depends on the state only, written in the circles, changes only at a clock edge, usually one more state (any two). (D1)
  9. NMH = 2.7 − 2.0 = 0.7 V. NML = 0.8 − 0.5 = 0.3 V. (E1)
  10. PAL: programmable AND array, fixed OR array; product terms cannot be shared; faster and cheaper. PLA: both arrays programmable; terms shared between outputs; more flexible. (E7)
  11. Inputs A, B, C, D in order. F = 1 when A = B = 1 or B = C = 1 or C = D = 1: minterms 3, 6, 7, 11, 12, 13, 14, 15. The K-map gives three groups of four: F = AB + BC + CD. Three 2-input AND gates and one 3-input OR gate (or NAND–NAND). Factored: F = B(A + C) + CD.
  12. P, Q, R on the select lines. Pairs (S = 0, S = 1): rows 0, 1 → 1, 0 → I0 = S'. Rows 2, 3 → 1, 0 → I1 = S'. Rows 4, 5 → 0, 1 → I2 = S. Rows 6, 7 → I3 = 0. Rows 8, 9 → 0, 1 → I4 = S. Rows 10, 11 → I5 = S. Rows 12, 13 → 1, 0 → I6 = S'. Rows 14, 15 → I7 = 1. (B1)
  13. Four variables need a 4:16 decoder (two 3:8 decoders, with a enabling one directly and the other through an inverter). F = OR of decoder outputs 0, 1, 2, 5, 6, 8, 9, 15: one 8-input OR gate, or an 8-input NAND if the outputs are active-low. (B2)
  14. States 00 → 01 → 10 → 11 → 00. Excitation (J1 K1, J0 K0): 00: 0X, 1X · 01: 1X, X1 · 10: X0, 1X · 11: X1, X1. K-maps: J0 = K0 = 1, J1 = K1 = Q0. Both flip-flops share the clock; FF0 toggles every pulse, FF1 toggles when Q0 = 1. (With T flip-flops: T0 = 1, T1 = Q0. With D: D0 = Q0', D1 = Q1 ⊕ Q0.) (C8)
  15. P₁ by outputs: (ADFG)(BCEH). P₂: on x = 1, D → B (other block) while A, F, G stay in their block, so D separates: (AFG)(BCEH)(D). P₃: A and F go to D; G goes to G, so G separates. On x = 1, E → F while B, C, H → D, so E separates: (AF)(BCH)(D)(E)(G). P₄ = P₃. Equivalent states: A ≡ F and B ≡ C ≡ H; 8 states become 5. (D3)
  16. Circuit and operation: E2. Fan-out: LOW state 8/0.4 = 20; HIGH state 400 μA/20 μA = 20; fan-out = 20. (E1)
  17. States: S0 nothing, S1 "1", S2 "10", S3 "101", S4 "1011" (z = 1). Table (next for x = 0, x = 1): S0 → S0, S1 · S1 → S2, S1 · S2 → S0, S3 · S3 → S2, S4 · S4 → S2, S1. Codes Y2Y1Y0: S0 000, S1 001, S2 010, S3 011, S4 100; codes 101–111 are don't-cares. D flip-flops: D2 = Y1Y0X · D1 = Y0X' + Y1Y0'X + Y2X' · D0 = Y1'X + Y0'X · z = Y2. (D2)
  18. K-maps give F1 = A'B + BC' + AB'C + A'C'D (four terms), F2 = A'B + AB'C, F3 = B + AC + AD. F1 does not fit in three terms, but two of its terms are F2: feed F2 back and write F1 = F2 + BC' + A'C'D. Programming table (columns A B C D F2; 1 = connected, 0 = complement connected, – = not connected). F2: A'B = 0 1 – – –; AB'C = 1 0 1 – –. F1: F2 = – – – – 1; BC' = – 1 0 – –; A'C'D = 0 – 0 1 –. F3: B = – 1 – – –; AC = 1 – 1 – –; AD = 1 – – 1 –. (E7)
  19. (a) 3 flip-flops; states 6 and 7 are don't-cares. From the state table and the JK excitation table: J0 = K0 = 1 · J1 = Q2'Q0, K1 = Q0 · J2 = Q1Q0, K2 = Q0. Self-start check: from 110, only FF0 toggles → 111. From 111: FF0 toggles to 0, FF1 resets (J1 = 0, K1 = 1), FF2 toggles to 0 → 000. Both unused states return to the count, so it is self-starting. (C8) (b) 3 flip-flops; clear at 6 = 110, so Q2 and Q1 feed the NAND gate. Disadvantage: ripple delay of up to 3tpd and false states (including a brief 110) on the outputs. (C7)
