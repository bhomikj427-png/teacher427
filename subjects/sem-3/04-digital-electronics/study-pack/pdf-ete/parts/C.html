Part C · Unit 3

Sequential logic

Every circuit in Parts A and B forgets its inputs the moment they change. A sequential circuit has memory: its output depends on the present inputs and on what happened before. Memory comes from feeding a gate's output back to its own input. This part builds the 1-bit memory (latch, then flip-flop), then rows of them (registers, counters).

Latch: a circuit with two stable states that stores one bit. · Set: make Q = 1. · Reset: make Q = 0. · Q': the second output, normally the complement of Q.
{{ sr_latch() }}

How it remembers. A NOR output is 0 if any input is 1. Put S = 1: the lower gate is forced to Q' = 0, so both inputs of the upper gate are 0 and Q = 1. Now return S to 0: Q = 1 is fed back into the lower gate and keeps Q' = 0. The loop holds the value that was set last. That is one bit of memory.

LatchWhat it adds
NAND SR latchThe same circuit with NAND gates. Its inputs are active-low: S' = 0 sets, R' = 0 resets, 11 holds, 00 is the forbidden case (Q = Q' = 1).
Gated SR latchAn enable input EN in front of S and R. The latch can change only while EN = 1; with EN = 0 it holds.
D latchA gated SR latch with S = D and R = D'. S and R can never both be 1, so the forbidden case is gone. While EN = 1, Q follows D (the latch is "transparent"). When EN goes to 0, Q keeps the last value.
Answer. Circuit and table above. With S = R = 1 both outputs are forced to 0, so Q and Q' are no longer complements. Worse, if S and R then return to 0 together, both gates try to go to 1 at once and the final state depends on which gate is faster: it is unpredictable.

C2 · Flip-flops

MUJ mid-term, 25 Sep 2025 · Q3 · 2 marks What excitation input should be applied to a T-FF to make output toggle?
Guess first: look at the two Q rows below. Which one would you want driving the next stage of a circuit, and why?
Clock (CLK): a square wave that tells every memory element when to update. · Edge: the instant the clock changes: positive (rising, 0 → 1) or negative (falling, 1 → 0). · Flip-flop: a 1-bit memory that updates only at a clock edge. A latch is level-triggered: it is open for as long as its enable is 1. · Toggle: change to the opposite value.
{{ latch_vs_ff() }}

Latch against flip-flop (same D, same clock). The latch follows D during the whole shaded time, including the short glitch. The flip-flop samples D only at each rising edge (↑) and ignores everything in between. In a synchronous system every flip-flop changes at the same instant, so signals are steady when they are read. That is why flip-flops, not latches, are used.

0 0Q (hold)000Q (hold)

1 01 (set)

These are the characteristic tables: given the inputs and the present Q, they give the next state Q⁺. The JK flip-flop is an SR flip-flop whose forbidden case 11 has been given a use (toggle). The SR flip-flop has the C1 table, applied at the clock edge. A T flip-flop is a JK with J = K = T. A D flip-flop is a JK with J = D, K = D'.

Race-around. In a level-triggered JK with J = K = 1, Q toggles, the new Q is fed back, and it toggles again, for as long as the clock stays 1. The final value is unknown.

{{ ms_jk() }}

Cure 1: master–slave JK (above). The master takes the inputs while CLK = 1; the slave copies the master when CLK = 0. They are never open together, so Q changes once per clock pulse.

Cure 2: edge triggering. The flip-flop responds only during the edge itself.

Asynchronous inputs. Most flip-flops also have PRESET (force Q = 1) and CLEAR (force Q = 0). They act at once, without waiting for the clock, and are usually active-low.

Answer. T = 1. The T flip-flop's rule is Q⁺ = T ⊕ Q: with T = 1 the output complements at every active clock edge, with T = 0 it holds.

Excitation table: the characteristic table read backwards. It answers: "to make Q go from this value to that value, what must the inputs be?" It is the table used in every design problem from here on.
Q → Q⁺S RJ KDTWhy (JK)

The X's are don't-cares, and they are why JK flip-flops usually give the simplest logic. D = Q⁺ always. T = 1 exactly when Q must change.

Ring counter: feed Q3 straight back to D0. Preset it to 1000 and the single 1 circulates: 1000 → 0100 → 0010 → 0001 → 1000. n flip-flops give MOD-n. Each Q marks one state, so no decoder is needed.

Johnson (twisted-ring) counter: feed Q3' back. The register fills with 1s, then empties: n flip-flops give MOD-2n. Each state is picked out by one 2-input AND gate (left table).

Lock-out. The Johnson counter uses 8 of the 16 states. If it ever lands in one of the other 8 (for example 0100) it circulates among those and never returns. Real designs start it with a reset, or add self-correcting logic.

Answer. Circuit above; sequence in the table: 8 states, MOD-8. Each Q is a square wave at one-eighth of the clock frequency, shifted one clock from its neighbour. Ring: n states from n flip-flops, no decoding. Johnson: 2n states from n flip-flops, 2-input decoding. Both waste states compared with a binary counter (2ⁿ states).

C7 · Asynchronous (ripple) counters

Professor's deck 10 · slides 12–13 Design an asynchronous decade counter.
Guess first: a decade counter has 10 states. How many flip-flops, and how do you stop it going on to 10, 11, … 15?
Counter: a circuit that steps through a fixed sequence of states, one step per clock pulse. · Asynchronous (ripple): only the first flip-flop gets the clock; each of the others is clocked by the output of the one before.
{{ ripple_counter() }}
{{ ripple_waves() }}

How it counts. Every flip-flop is set to toggle (T = 1, or J = K = 1). FF0 toggles on every falling clock edge. FF1 toggles whenever Q0 falls, FF2 whenever Q1 falls. Reading Q2Q1Q0 gives 0, 1, 2, … 7, 0: an up counter. Each Q is a square wave at half the frequency of the one before, so the counter is also a frequency divider. Clock each stage from Q' instead and it counts down. (With positive-edge flip-flops the rule swaps: Q' for up, Q for down.)

The flaw: ripple delay. Each stage waits for the one before. After the 4th edge (011 → 100) the outputs pass through 010 and 000 before settling (shaded). The worst settling time is n·tpd, where tpd is one flip-flop's delay. Anything reading the outputs sees these false states for a moment, and the clock period must be longer than n·tpd.

MOD less than 2ⁿ. Use the smallest n with 2ⁿ ≥ MOD. Let the counter run normally, detect the first unwanted state with a NAND gate, and use that to drive the asynchronous CLEAR of every flip-flop.

Cascading (deck 10 slides 16–17). Clock a second counter from the last output of the first: MOD-M followed by MOD-N gives MOD-(M × N). A MOD-4 and a MOD-8 counter make MOD-32.

Answer. 2³ = 8 < 10 ≤ 16 = 2⁴, so 4 flip-flops Q3 Q2 Q1 Q0, all toggling, each clocked by the Q before it (negative edge). The first unwanted state is 10 = 1010, the first state in which Q3 and Q1 are both 1. A 2-input NAND on Q3 and Q1 drives all the active-low CLEAR inputs. The count goes 0000 … 1001, shows 1010 for a few nanoseconds, and is cleared to 0000.

(b) Deck 10 slide 14: which outputs go to the NAND gate of a MOD-7 asynchronous up counter? Of a MOD-12 counter? (c) How many flip-flops does a MOD-60 counter need? Synchronous counter: every flip-flop gets the same clock, so all outputs change together. Gates on the flip-flop inputs decide which ones change. No ripple delay and no false states.

  1. Number of flip-flops: smallest n with 2ⁿ ≥ number of states.
  2. State table: each present state and the next state.
  3. For each flip-flop, fill in its inputs from the excitation table (C3), row by row.
  4. K-map each input as a function of the present state. Unused states are don't-cares.
  5. Draw the circuit: common clock, gates from step 4.
  6. If there are unused states, check that each one leads back into the count (self-starting).

C9 · Timing analysis of sequential circuits

Practice A synchronous circuit has flip-flop delay tpd = 8 ns, setup time tsu = 3 ns, hold time th = 2 ns, and combinational delays of 12 ns on the longest path and 1 ns on the shortest. Find the maximum clock frequency and check the hold time.
Guess first: the data leaves one flip-flop at a clock edge. By when must it have arrived at the next flip-flop?
{{ setup_hold() }}
Setup time tsu: D must be steady for this long before the clock edge. · Hold time th: D must stay steady for this long after the edge. · Propagation delay tpd: time from the clock edge until Q is valid. · Metastability: if setup or hold is broken, the output can hang between 0 and 1 for an unpredictable time.
{{ timing_path() }}

Setup condition (longest path). Data launched at one edge must pass through the flip-flop and the slowest logic and still arrive one setup time before the next edge:

Tclk ≥ tpd + tcomb,max + tsu     fmax = 1/Tclk,min

Hold condition (shortest path). The new data must not arrive while the next flip-flop is still holding the old value: tpd + tcomb,min ≥ th. The clock period is not in this inequality, so slowing the clock cannot fix a hold violation; extra delay must be added to the short path.

Answer. Tmin = 8 + 12 + 3 = 23 ns, so fmax = 1/23 ns = 43.5 MHz. Hold: 8 + 1 = 9 ns ≥ 2 ns, so hold is met.
