Part A · Unit 1

Combinational logic design

A digital signal has two values, written 0 and 1. A combinational circuit is one whose output depends only on its present inputs. This part builds the tools to describe such a circuit (Boolean algebra), shrink it (K-map), build it from one kind of gate (NAND or NOR), and then uses them on the first real circuits: adders.

A1 · Gates and the laws of Boolean algebra

Professor's deck 01 · slide 18 "Algebraic manipulation" Simplify F = x'yz + x'yz' + xz.
Guess first: which two terms differ in only one variable?
Variable: a letter that is 0 or 1. · Complement x': 1 when x is 0, and 0 when x is 1. · Literal: a variable or its complement (x and x' are two literals). · Gate: a circuit that performs one logic operation.
{{ gates_row() }}

Three basic operations. AND (A·B, written AB) is 1 only when both inputs are 1. OR (A + B) is 1 when at least one input is 1. NOT (A') inverts. NAND and NOR are AND and OR followed by NOT. XOR (A ⊕ B = A'B + AB') is 1 when the inputs differ; XNOR (A ⊙ B) is 1 when they are equal. A function of n variables has a truth table of 2ⁿ rows, one per input combination.

LawOR formAND form
Identity, nullX + 0 = X · X + 1 = 1X·1 = X · X·0 = 0
Idempotent, complementX + X = X · X + X' = 1X·X = X · X·X' = 0
Involution(X')' = X
DistributiveX + YZ = (X + Y)(X + Z)X(Y + Z) = XY + XZ
AbsorptionX + XY = X · X + X'Y = X + YX(X + Y) = X
De Morgan(X + Y)' = X'·Y'(X·Y)' = X' + Y'
ConsensusXY + X'Z + YZ = XY + X'Z (the term YZ is redundant)

Duality. Swap + with · and 0 with 1 in any law and you get another true law. That is why the table has two columns. De Morgan in words: break the bar, change the sign.

Answer. The first two terms differ only in z. F = x'y(z + z') + xz = x'y·1 + xz = x'y + xz. Three 3-input ANDs became two 2-input ANDs.

A2 · Minterms, maxterms and canonical forms

Professor's deck 01 · slides 27–29 f1(a, b, c) is 1 for the input rows 001, 010, 100 and 110. Write it as a sum of minterms (Σm) and as a product of maxterms (ΠM).
Guess first: Σm lists the rows where the function is 1. Which rows does ΠM list?
Minterm mj: an AND of all the variables that is 1 for exactly one row, row j. A variable is complemented where the row has a 0. · Maxterm Mj: an OR of all the variables that is 0 for exactly one row. A variable is complemented where the row has a 1. So Mj = mj'.

Canonical SOP (sum of products): OR together the minterms of the rows where F = 1. Canonical POS (product of sums): AND together the maxterms of the rows where F = 0. Both are unique for a function. To convert one to the other, swap Σ and Π and list the missing row numbers.

Standard form is SOP or POS in which terms may have fewer literals (a'b'c + bc' + ac'). To make it canonical, multiply each short term by (x + x') for every missing variable x, then remove repeats: bc' = (a + a')bc' = abc' + a'bc'.

Answer. f1 = Σm(1, 2, 4, 6) = a'b'c + a'bc' + ab'c' + abc'. The rows left out are 0, 3, 5, 7, so f1 = ΠM(0, 3, 5, 7) = (a + b + c)(a + b' + c')(a' + b + c')(a' + b' + c').

A3 · The Karnaugh map

MUJ mid-term, 25 Sep 2025 · Q4 · 4 marks Minimize the following Boolean function using K-Map method to obtain a simplified expression. Also draw the logic circuit using basic gates. F(a, b, c, d) = Σm(0, 4, 5, 7–9, 15) + Σd(1, 3, 6, 14)
Guess first: a don't-care can be read as 0 or 1. When would you choose 1?
K-map: the truth table redrawn as a grid, ordered 00, 01, 11, 10 so that neighbouring cells differ in exactly one variable. · Don't-care (X): an input combination that never occurs, or whose output does not matter. · Prime implicant: a group that cannot be made any larger. · Essential prime implicant: a prime implicant that covers some 1 no other prime implicant covers.
{{ km("abcd", [0,4,5,7,8,9,15], [1,3,6,14], ["b'c'", "bc", "a'c'"]) }}

Why grouping works. Two neighbouring 1s differ in one variable x, so their sum is (rest)(x + x') = rest. The variable that changes inside a group drops out.

Rules for groups (deck 02 slides 4–10):

  • Only 1s (and X's you choose to use), never a 0.
  • Rectangles of 1, 2, 4, 8 … cells. No diagonals.
  • The map wraps around: left edge touches right edge, top touches bottom.
  • Make each group as large as possible, and use as few groups as possible.
  • Every 1 must be in at least one group. Groups may overlap.

A group of 2ᵏ cells removes k variables. In a 4-variable map: 8 cells → 1 literal, 4 cells → 2 literals, 2 cells → 3 literals.

Procedure. (1) Put a 1 in each minterm cell, X in each don't-care cell (the small number in each cell is its minterm number). (2) Find the essential prime implicants first. (3) Cover the remaining 1s with the fewest, largest groups. (4) Read each group: keep only the variables that stay the same across it; write the variable if it stays 1, its complement if it stays 0. Use an X only when it makes a group of 1s bigger. An X never needs to be covered.

Answer. Top row and bottom row join by wrap-around: cells 0, 1, 8, 9 → b'c' (X at 1 used). Cells 6, 7, 14, 15 → bc (X at 6 and 14 used). The 1s left are 4 and 5: cells 0, 1, 4, 5 → a'c'. X at 3 is not needed, so it is read as 0.

F = b'c' + bc + a'c'

Cells 4, 5, 6, 7 (a'b) cover 4 and 5 equally well, so F = b'c' + bc + a'b is also minimal. Circuit: three 2-input AND gates into one 3-input OR gate, with inverters for a', b', c' (figure below).

Professor's deck 02 · slide 63 "PoS optimization from SoP" F(W, X, Y, Z) = Σm(0, 1, 2, 5, 8, 9, 10). Find the minimal SOP and the minimal POS. "Which one is the minimal one?"
Guess first: to get a product of sums, which cells do you group?
{{ km("WXYZ", [0,1,2,5,8,9,10], [], ["X'Y'", "X'Z'", "W'Y'Z"], title="SOP: group the 1s") }}
{{ km("WXYZ", [0,1,2,5,8,9,10], [], ["(W' + X')", "(Y' + Z')", "(X' + Z)"], pos=True, title="POS: group the 0s") }}

POS method. Group the 0s with the same rules. Each group gives one sum term, read the opposite way round: a variable that stays 0 across the group is written plain, one that stays 1 is written complemented. AND the sum terms together. (Reason: grouping the 0s gives F' as a sum of products; complementing it with De Morgan gives F as a product of sums.)

Answer. SOP: F = X'Y' + X'Z' + W'Y'Z (7 literals). POS: the 0s group as WX (cells 12–15), YZ (cells 3, 7, 11, 15) and XZ' (cells 4, 6, 12, 14), so F = (W' + X')(Y' + Z')(X' + Z) (6 literals). Both need three gates plus one output gate; the POS form is one literal cheaper. Always work out both when the question asks for "minimal".

A7 · Parallel adder, carry look-ahead, adder–subtractor

Professor's deck 03 · slides 18–19 Add A = 1011 (eleven) and B = 1110 (fourteen) in a 4-bit ripple-carry adder, showing every carry. If each gate has delay T, what is the delay of an n-bit ripple-carry adder?
Guess first: which output bit is the last one to become correct?
{{ ripple_adder() }}

Parallel (ripple-carry) adder. One full adder per bit; each carry-out feeds the next carry-in. All bits of A and B arrive together, but the carry has to ripple from the right end to the left end, so the top bits settle last.

Carry look-ahead (CLA) removes the wait. For each bit define

Gi = AiBi (generate)   Pi = Ai ⊕ Bi (propagate)

A stage produces a carry if it generates one, or if it passes on the one coming in: Ci+1 = Gi + PiCi. Substituting each carry into the next:

C1 = G0 + P0C0
C2 = G1 + P1G0 + P1P0C0
C3 = G2 + P2G1 + P2P1G0 + P2P1P0C0

Every carry is now a two-level AND–OR of the inputs and C0, so all carries are ready together, and Si = Pi ⊕ Ci. The price is more and wider gates.

{{ cla_delay() }}

Adder–subtractor. In 2's complement, A − B = A + B' + 1. Put an XOR on each B input, controlled by a mode line M, and use M as the first carry-in:

{{ ripple_adder(True) }}

M = 0: each XOR passes B unchanged and C0 = 0, so the circuit adds. M = 1: each XOR gives B' and C0 = 1, so it computes A + B' + 1 = A − B. For unsigned numbers, a final carry of 1 after subtraction means the result is positive (discard the carry); a final carry of 0 means it is negative and is in 2's-complement form.

Answer. Bit 0: 1 + 0 + 0 → S0 = 1, C1 = 0. Bit 1: 1 + 1 + 0 → S1 = 0, C2 = 1. Bit 2: 0 + 1 + 1 → S2 = 0, C3 = 1. Bit 3: 1 + 1 + 1 → S3 = 1, Cout = 1. Result 1 1001 = 25 ✓. Delay, counting as the deck does (one gate delay T for the first XOR level, then two gate levels per carry stage): the last carry needs 2n·T and the total is (2n + 1)T. For n = 4 that is 9T.

A8 · Serial adder and BCD adder

Professor's deck 09 · slides 25–26 "An application: serial addition" A serial adder holds A = 0100 and B = 0111 in two shift registers. Trace the four clock pulses and give the final contents of register A.
Guess first: a serial adder has only one full adder. Where does it keep the carry between bits?
Shift register: a row of storage cells that moves its contents one place per clock pulse (built in C5). Here it only needs to hand out one bit per clock, least significant bit first. · BCD: binary-coded decimal. Each decimal digit 0–9 is stored as its own 4-bit number, so 1010 to 1111 are not valid digits.
{{ serial_adder() }}

Serial adder. One full adder is reused for every bit position. On each clock the two registers present their lowest bits, the sum bit shifts back into the top of A, and a flip-flop stores the carry for the next clock. It needs 1 full adder and 1 flip-flop for any word length, but takes n clocks. A parallel adder needs n full adders and takes one step.

BCD adder. Add two BCD digits with an ordinary 4-bit adder. If the result is more than 9, it is not a valid digit and the decimal carry has been missed. Adding 6 (0110) fixes both, because a 4-bit adder rolls over at 16 and a decimal digit should roll over at 10: 16 − 10 = 6.

{{ bcd_adder() }}

Correction is needed when the first adder gives a carry K (sum 16–19) or its sum is 10–15. The K-map of "Z ≥ 10" gives Z3Z2 + Z3Z1, so Y = K + Z3Z2 + Z3Z1. Example: 8 + 7 → 1000 + 0111 = 1111 (15), Y = 1, add 0110 → 1 0101: carry 1, digit 5, which reads 15 ✓.

Answer. The table above: after four clocks register A holds 1011 (4 + 7 = 11) and the carry flip-flop holds 0.
