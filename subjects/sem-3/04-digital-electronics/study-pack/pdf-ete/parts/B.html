B1 · The multiplexer (MUX)

MUJ mid-term, 25 Sep 2025 · Q5 · 4 marks Implement the following function using single 8:1 Multiplexer. F(P, Q, R, S) = Σm(0, 1, 3, 4, 8, 9, 10, 11, 13, 15)
Guess first: an 8:1 MUX has 3 select lines but the function has 4 variables. Where does the fourth variable go?
Multiplexer: a switch with many data inputs I0, I1, … and one output. · Select lines: a binary number that picks which data input reaches the output. A 2ⁿ:1 MUX has n select lines. 4:1 MUX: Y = S1'S0'I0 + S1'S0I1 + S1S0'I2 + S1S0I3.

A MUX is a truth table in hardware. Put the variables on the select lines, and each data input becomes one row of the table.

  • n variables, 2ⁿ:1 MUX: all variables on the selects; each Ij is the constant 0 or 1 from row j.
  • n variables, 2ⁿ⁻¹:1 MUX: put n − 1 variables on the selects. Each select code now covers two rows, the last variable = 0 and = 1. Compare F in those two rows with the last variable:

Unit 2 › Decoder · asked in the 2025 mid-term

B2 · Decoder and demultiplexer

MUJ mid-term, 25 Sep 2025 · Q6 · 4 marks Design Full Adder using suitable decoder.
Guess first: a full adder has 3 inputs. How many outputs must the decoder have, and what is each output in the language of A2?
Decoder (n to 2ⁿ): n inputs, 2ⁿ outputs; exactly one output is active, the one whose number equals the input code. Output j is therefore minterm mj. · Enable: an extra input that switches every output off when inactive. · Active-low output: the selected output goes to 0 and the others stay at 1 (drawn with a bubble).
{{ decoder_fig() }}

Any function = decoder + one OR gate per output. The decoder already makes every minterm, so OR together the minterms in the function's Σm list. If the decoder outputs are active-low (as on the 74138 chip), each output is mj', so use a NAND gate instead: NAND(m1', m2') = m1 + m2.

{{ demux_fig() }}

Demultiplexer: the reverse of a MUX. One data input D is routed to the output chosen by the select lines; the others stay 0.

A decoder with an enable is a demultiplexer: use the code inputs as selects and feed the data into the enable.

Bigger decoders from smaller ones (deck 05 slide 14): a 4:16 decoder is two 3:8 decoders. The lower three bits go to both; the top bit enables one decoder directly and the other through an inverter.

Answer. Use a 3:8 decoder with inputs A, B, Cin (A = most significant). From the full-adder table (A6): S = Σm(1, 2, 4, 7) and Cout = Σm(3, 5, 6, 7). OR decoder outputs 1, 2, 4, 7 for S, and outputs 3, 5, 6, 7 for Cout (figure above). Two 4-input OR gates; with an active-low decoder, two 4-input NAND gates.
Check B2. (a) Professor's practice set 1, Q7: realize Y = ΠM(0, 3, 5, 6, 7) with a decoder and one NOR gate. (b) Deck 05 slide 20: realize F(X, Y, Z) = Σm(1, 2, 5, 7) with a 3:8 decoder whose outputs are active-low. (c) How many 3:8 decoders, and what else, make a 4:16 decoder?
Unit 2 › Encoder

B3 · Encoder and priority encoder

Practice · deck 05 slides 36–43 Design a 4-to-2 priority encoder with a valid output.
Guess first: a plain encoder assumes only one input is 1. What should happen if two are 1 at once?
Encoder (2ⁿ to n): the reverse of a decoder. One of its 2ⁿ inputs is active and the output is that input's number in binary. · Priority encoder: if several inputs are active, it outputs the number of the highest-numbered one. · Valid (V): an extra output that is 1 when at least one input is active.
w3 w2 w1 w0y1 y0V
0 0 0 0X X0
0 0 0 10 01
0 0 1 X0 11
0 1 X X1 01
1 X X X1 11

Reading the table. X on the input side means "whatever this is": once w3 = 1 the lower inputs are ignored. Each row with X's stands for several rows of the full 16-row table.

Plain 4-to-2 encoder (one input at a time): y1 = w2 + w3, y0 = w1 + w3. Two problems: w1 and w2 together give 11, which is wrong; and "no input" gives 00, the same as w0. Priority and V fix both.

Answer. From the table (K-map with the all-zero row as a don't-care):

y1 = w3 + w2     y0 = w3 + w2'w1     V = w3 + w2 + w1 + w0

The w2' in y0 is the priority: w1 counts only if w2 is not active.

Used for: keyboard encoding (decimal-to-BCD encoder, 10 keys to 4 bits) and interrupt handling, where the highest-priority request must win.

Check B3. (a) The inputs are w3w2w1w0 = 0110. Give y1y0 and V. (b) Write y0 for a plain 8-to-3 encoder with inputs w0…w7. (c) Why is V needed?
Unit 2 › Display

B4 · BCD to 7-segment decoder/driver and multiplexed display

Professor's practice set 1 · Q10 Design a BCD to 7-segment decoder circuit for a common anode display.
Guess first: in a common-anode display all the LED anodes are tied to +5 V. Does a segment light on a 1 or on a 0?
7-segment display: seven LED bars named a to g. · Common cathode: all cathodes grounded; a segment lights when its line is 1. · Common anode: all anodes at +V; a segment lights when its line is 0. · Driver: an output stage that can supply the 10–20 mA an LED needs (through a current-limiting resistor).

Multiplexed display. With several digits, one decoder is shared. The segment lines of all digits are wired together, and the digits are enabled one at a time, each with its own BCD value, faster than the eye can follow (each digit refreshed more than about 50 times a second). N digits need 7 + N lines instead of 7N, and one decoder instead of N.

Unit 2 › Comparator

B5 · Magnitude comparator

Professor's deck 06 · slides 3–6 Design a 2-bit magnitude comparator: outputs G (A > B), E (A = B), L (A < B) for A = A1A0 and B = B1B0.
Guess first: to compare 5234 with 5199 by hand, which digit do you look at first, and when do you stop?
{{ comparator_flow() }}

One bit. G = AB' (A is 1, B is 0). L = A'B. E = (A ⊕ B)' = A ⊙ B. Write xi = Ai ⊙ Bi for "bit i is equal".

More bits. Compare from the most significant bit down. The first position where the bits differ decides; lower bits matter only while all higher bits are equal.

2-bit4-bit (the 7485 chip)
E (A = B)x1x0x3x2x1x0
G (A > B)A1B1' + x1A0B0'A3B3' + x3A2B2' + x3x2A1B1' + x3x2x1A0B0'
L (A < B)A1'B1 + x1A0'B0same with A' and B swapped in; or L = (G + E)'
Answer. A 16-row truth table (4 inputs) and one K-map per output give

G = A1B1' + A0B1'B0' + A1A0B0'

L = A1'B1 + A1'A0'B0 + A0'B1B0    E = (A1 ⊙ B1)(A0 ⊙ B0)

These are the table's 2-bit formulas multiplied out.

Cascading. The 7485 has three cascade inputs (A>B, A=B, A<B) that carry the result from the lower 4 bits. For 8 bits, the outputs of the low-order chip feed the cascade inputs of the high-order chip. Uses: address decoding, and control systems that compare a measured value with a set value.

Check B5. (a) A = 0101, B = 0100. At which bit is the comparison decided, and which output is 1? (b) Write E for a 1-bit comparator using only AND, OR, NOT. (c) Why can L be made from G and E with one gate?
Unit 2 › Parity · asked in the 2025 mid-term

B6 · Parity generator and checker

MUJ mid-term, 25 Sep 2025 · Q2 · 2 marks The four-bit binary sequence 1011 is applied to an even parity generator circuit. What will be the output?
Guess first: count the 1s in 1011. Is the count already even?
Parity bit: one extra bit sent with a data word so the receiver can detect an error. · Even parity: the parity bit makes the total number of 1s (data + parity) even. · Odd parity: it makes the total odd.
{{ parity_fig() }}

Generator. XOR of several bits is 1 exactly when an odd number of them are 1. So the even-parity bit is the XOR of all the data bits: if the count is odd, P = 1 makes it even. The odd-parity bit is the complement (XNOR). For three bits (deck 06 slide 13): Peven = X ⊕ Y ⊕ Z, Podd = (X ⊕ Y ⊕ Z)'.

Checker. The receiver XORs all received bits including the parity bit. With even parity the result E should be 0; E = 1 means an error. A single parity bit detects any odd number of wrong bits. It misses two wrong bits, and it cannot say which bit is wrong.

Answer. 1011 has three 1s (odd). P = 1 ⊕ 0 ⊕ 1 ⊕ 1 = 1. The word sent is 1011 with parity bit 1, which has four 1s.
Check B6. (a) What is the odd parity bit for 1011? (b) A receiver using even parity gets data 1001 and parity bit 1. Is there an error? (c) Professor's practice set 1, Q9: describe the logic diagram of a 4-bit odd/even parity generator.

Guess first: 110110 is a negative number in 2's complement. After a right shift, what should the new leftmost bit be to keep it negative?

Arithmeticright shift: a copy of the sign bit (leftmost bit). Left shift: 0÷ 2 that keeps the sign of a 2's-complement number

Barrel shifter. A shift register (C5) moves one place per clock. A barrel shifter is combinational: it shifts by any number of places in one step, using multiplexers. For a 4-bit rotate-left, each output bit has a 4:1 MUX and the shift amount S1S0 goes to every select:

S1S0Y3 Y2 Y1 Y0
00D3 D2 D1 D0
01D2 D1 D0 D3
10D1 D0 D3 D2
11D0 D3 D2 D1

An n-bit barrel shifter needs n MUXes of size n:1 (or log₂n rows of 2:1 MUXes that shift by 1, 2, 4, …).

Answer. (i) 011000. (ii) 011011: the two bits 11 that leave the left end come back in at the right. (iii) 111011: the sign bit 1 is copied into the empty place.

Unit 2 › ALU

B8 · Arithmetic logic unit (ALU)

Professor's deck 07 · slides 9–10 Design an arithmetic circuit with inputs A and B. The circuit generates the following four arithmetic operations: addition, subtraction, increment and decrement.
Guess first: an adder computes A + (something) + carry-in. What "something" and carry-in give A − 1?
ALU: the block of a processor that does the arithmetic (add, subtract, increment, decrement) and the logic (AND, OR, XOR, NOT) on two words. Select lines choose the operation.

The idea. Keep one parallel adder (A7) and change what is fed to its B input. Call that input Y. Two select lines choose Y, and the first carry-in Cin is a third control:

Yi = BiS0 + Bi'S1     F = A + Y + Cin

S1 S0YCin = 0Cin = 1
0 0all 0sF = A (transfer)F = A + 1 (increment)
0 1BF = A + B (add)F = A + B + 1
1 0B'F = A + B'F = A + B' + 1 = A − B (subtract)
1 1all 1sF = A − 1 (decrement)F = A (transfer)

All 1s is −1 in 2's complement, which is why adding it decrements. Each stage is one full adder with inputs Ai, Yi, Ci, plus two AND gates and one OR gate for Yi.

{{ alu_fig() }}

Full ALU. A logic unit computes AND, OR, XOR and NOT of the same bits, and a MUX on each bit picks the arithmetic or the logic result. The ALU also outputs status flags: carry, zero, sign, overflow.

Answer. The table above, with the four asked operations in bold: add (S1S0 = 01, Cin = 0), subtract (10, 1), increment (00, 1), decrement (11, 0). Logic diagram of the first two stages: two full adders in a ripple chain; stage i has inputs Ai and Yi = BiS0 + Bi'S1; Cin enters stage 0 and its carry-out feeds stage 1.

MUX 2 inputs: 1, D, D, 1 (rows 8–9, 10–11, 12–13, 14–15). MUX 3 uses A on its low select line with the other select grounded: I0 = MUX 1 output, I1 = MUX 2 output.

(Equivalently Y = Σm(1, 2, 4).) (b) A 4-input NAND on outputs 1, 2, 5, 7. (c) Two 3:8 decoders with enables, plus one inverter for the top bit.
