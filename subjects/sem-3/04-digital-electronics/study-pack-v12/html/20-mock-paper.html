20 — Mock end-term paper

Closed book, on paper, 3 hours · do it after the rest · then mark it with the key on the last pages and redo anything you missed

No Digital Electronics end-term paper or blueprint has been seen, so the format is a guess. This paper copies the layout of the one official blueprint in hand (MAS2001, July–Nov 2026): Part A 10 × 2, Part B 6 × 6, Part C 2 × 8, Part D 1 × 8, total 80. Questions with a source tag are the professor's own and are not used earlier in the pack.

Part A · 10 × 2 = 20 marks

  1. State De Morgan's two theorems.
  2. Convert F(A, B, C) = Σm(1, 3, 6) to product-of-maxterms form.
  3. Why is the NAND gate called a universal gate?
  4. How many select lines does a 16:1 MUX have? How many 4:1 MUXes build it as a tree?
  5. Find the odd parity bit for 1101001.
  6. Give two differences between a latch and a flip-flop.
  7. How many flip-flops does a MOD-12 counter need, and how many states are unused?
  8. Give two differences between Mealy and Moore machines.
  9. VOH(min) = 2.7 V, VIH(min) = 2.0 V, VIL(max) = 0.8 V, VOL(max) = 0.5 V. Find the noise margins.
  10. Differentiate PAL and PLA.

Part B · 6 × 6 = 36 marks

  1. Set 1 Q4 Design a combinational circuit having 4 inputs that will produce an output '1' when two consecutive input bits are 1 and produce '0' for other cases.
  2. Set 1 Q6 Implement F(P, Q, R, S) = Σm(0, 2, 5, 9, 11, 12, 14, 15) using an 8:1 multiplexer.
  3. Set 1 Q8 Implement F(a, b, c, d) = Σm(0, 1, 2, 5, 6, 8, 9, 15) using a suitable decoder.
  4. Set 2 Q4 Design a 2-bit synchronous up counter with JK flip-flops: state table, excitation table, equations.
  5. Deck 12 slide 18 Reduce by partitioning (next/z for x = 0; for x = 1): A D/0, D/0 · B C/1, D/0 · C C/1, D/0 · D D/0, B/0 · E C/1, F/0 · F D/0, D/0 · G G/0, G/0 · H B/1, D/0.
  6. Draw a two-input TTL NAND with totem-pole output and explain it. IOL = 8 mA, IIL = 0.4 mA, IOH = 0.4 mA, IIH = 20 μA: find the fan-out.

Part C · 2 × 8 = 16 marks

  1. Deck 11 slide 43 Q1 Design a Moore circuit to detect 1011 (overlap allowed) with D flip-flops: state diagram, state table, input equations.
  2. Deck 15 slide 28 Realise with a PAL of three product terms per output: F1(A, B, C, D) = Σm(1, 4–7, 10–13), F2 = Σm(4–7, 10–11), F3 = Σm(4–7, 9–15). Give the minimal expressions and the programming table.

Part D · 1 × 8 = 8 marks

  1. (a) Design a MOD-6 synchronous up counter (0–5) with JK flip-flops and check whether it is self-starting. (b) For an asynchronous MOD-6 instead: flip-flops, reset-gate inputs, and one disadvantage.

Key

Part A.

  1. (X + Y)' = X'Y' and (XY)' = X' + Y'. (01)
  2. ΠM(0, 2, 4, 5, 7). (01)
  3. NOT, AND and OR can each be built from NANDs alone, so any function can. (03)
  4. 4 select lines; five 4:1 MUXes. (05)
  5. Four 1s (even): odd parity bit 1. (07)
  6. Latch: level-triggered, transparent while enabled, passes glitches. Flip-flop: edge-triggered, samples once per clock. (09)
  7. 4 flip-flops; 4 unused states. (12)
  8. Mealy: output from state and input, on arrows, fewer states. Moore: from state only, in circles, one more state (any two). (15)
  9. NMH = 0.7 V, NML = 0.3 V. (18)
  10. PAL: programmable AND, fixed OR, no sharing. PLA: both programmable, terms shared. (19)

Part B.

  1. F = 1 for minterms 3, 6, 7, 11, 12, 13, 14, 15. K-map: three quads, F = AB + BC + CD: three 2-input ANDs and a 3-input OR (or NAND–NAND).
  2. P, Q, R on the selects. I0 = S', I1 = S', I2 = S, I3 = 0, I4 = S, I5 = S, I6 = S', I7 = 1. (05)
  3. A 4:16 decoder (two 3:8s, a enabling one directly and the other through an inverter); OR outputs 0, 1, 2, 5, 6, 8, 9, 15 (8-input NAND if active-low). (06)
  4. 00 → 01 → 10 → 11 → 00. Excitation (J1K1, J0K0): 00: 0X, 1X · 01: 1X, X1 · 10: X0, 1X · 11: X1, X1. J0 = K0 = 1, J1 = K1 = Q0. (13)
  5. P1: (ADFG)(BCEH). P2: on x = 1, D → B (other block): D separates → (AFG)(BCEH)(D). P3: A, F → D but G → G: G separates; on x = 1, E → F but B, C, H → D: E separates → (AF)(BCH)(D)(E)(G). P4 = P3. A ≡ F, B ≡ C ≡ H: 8 states become 5. (16)
  6. Circuit and operation: 18 §2. Fan-out: 8/0.4 = 20 and 400/20 = 20: 20.

Part C.

  1. S0 nothing, S1 "1", S2 "10", S3 "101", S4 "1011" (z = 1). Next (x = 0, x = 1): S0 → S0, S1 · S1 → S2, S1 · S2 → S0, S3 · S3 → S2, S4 · S4 → S2, S1. Codes Y2Y1Y0: 000, 001, 010, 011, 100; 101–111 don't-care. D2 = Y1Y0X · D1 = Y0X' + Y1Y0'X + Y2X' · D0 = Y1'X + Y0'X · z = Y2. (15)
  2. F1 = A'B + BC' + AB'C + A'C'D (four terms), F2 = A'B + AB'C, F3 = B + AC + AD. F1 does not fit in three terms, but two of its terms are F2: feed F2 back, F1 = F2 + BC' + A'C'D. Table (A B C D F2; 1 = true, 0 = complement, – = none): F2: A'B = 0 1 – – –; AB'C = 1 0 1 – –. F1: F2 = – – – – 1; BC' = – 1 0 – –; A'C'D = 0 – 0 1 –. F3: B = – 1 – – –; AC = 1 – 1 – –; AD = 1 – – 1 –. (19)

Part D.

  1. (a) 3 flip-flops; 6, 7 don't-care. J0 = K0 = 1 · J1 = Q2'Q0, K1 = Q0 · J2 = Q1Q0, K2 = Q0. Self-start: 110 → 111 (only FF0 toggles); 111 → 000. Both return: self-starting. (13) (b) 3 flip-flops; clear at 110: Q2, Q1 into the NAND. Disadvantage: ripple delay up to 3tpd and false states (a brief 110) on the outputs. (12)
