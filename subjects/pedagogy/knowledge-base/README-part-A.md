# Part A — The Science of Learning, by Kind of Information

> A guide to how Part A fits together. It holds no live state: stage and sprint status live in
> `00-map.md` and `../progress-log.md`. Source IDs → `sources.md`; traps → `misconceptions.md`.

## The story in eight steps (one per unit)

1. **A1 — Studying is not learning.** Performance during study (how fluent it feels, how well you
   do right now) is a poor guide to learning (durable, unaided, transferable). Storage strength vs
   retrieval strength explains why. Retrieval is itself a learning event.
2. **A2 — The machinery.** A small working memory (~4 chunks) feeds a large long-term memory with
   several systems (declarative, procedural, …). Encoding → consolidation (sleep) → retrieval;
   forgetting is mostly interference, and some forgetting helps.
3. **A3 — Kinds of information (the hub).** Eight rows: facts, concepts, principles, procedures,
   conditional knowledge, metacognitive, perceptual, motor. Each row is learned by a different
   process (memory & fluency / induction / sense-making) and fails in its own way.
4. **A4 — Kind → method.** Every row gets a best-evidenced first method (retrieval + spacing for
   facts; varied interleaved examples for concepts; self-explanation for principles; worked
   examples → fading for procedures; mixed problem types for conditional knowledge …), graded S/M/T/X.
5. **A5 — Schemas, expertise, transfer.** Experts get around the working-memory limit with large
   chunks and see deep structure; methods must change as expertise grows; transfer is hard and
   must be practised (compare analogs, name the principle).
6. **A6 — Depth and generation.** Producing beats receiving (generation effect; ICAP). Retrieval is
   generation from memory, so "encoding vs retrieval" is a false split: choose the *prompt* by row.
   Prequestions help what they ask; concept maps help but lose to retrieval.
7. **A7 — Metacognition.** Monitoring feeds control. Feelings during study mislead; delayed
   retrieval attempts monitor accurately; stop by criterion across days, not by feel.
8. **A8 — Myths and a test kit.** Learning styles, left/right brain, the learning pyramid,
   multitasking, Pomodoro-as-learning, mindset-as-lever: why each feels true and why it fails, plus
   seven questions to test any learning claim.

## Threshold concepts (check these hardest)
1. Learning ≠ performance (A1)
2. Working-memory bottleneck; schemas get around it (A2 → A5)
3. The best method depends on the kind of information (A3/A4)
4. Retrieval is itself an encoding event (A1 §5, A6 §7)
5. Some forgetting is useful (A1/A2)
