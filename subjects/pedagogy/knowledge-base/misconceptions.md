# Pedagogy — Misconceptions (seed, S1)

> One line per misconception: the wrong belief → the correction → source → unit that teaches it.
> `seed` = listed in S1, correction to be written fully in its unit's sprint. Grows every sprint.

| # | Misconception | Correction (short) | Source | Unit | Status |
|---|---|---|---|---|---|
| M1 | Time spent studying = learning | Learning is a lasting change you can show later and unaided; hours measure input, not output | SB15 | A1 | seed |
